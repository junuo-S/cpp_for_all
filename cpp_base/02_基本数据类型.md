# 02_基本数据类型

### 2.1 概述

在程序设计中，数据类型用于描述一段数据的含义、可进行的操作以及它在内存中的存储方式。没有数据类型，计算机无法判断某块内存中的比特序列应该被解释为整数、字符还是浮点数。因此，数据类型是编程语言理解与处理信息的基础。

不同语言对类型的约束不同：

* **强类型语言**会严格限制不同类型之间的操作与转换，避免产生意外的逻辑错误。
* **弱类型语言**在类型转换上更灵活，编译器或运行时会自动进行隐式类型转换，写法更自由但更容易隐藏错误。

C++ 是一种 **强类型、静态类型** 的语言。它的变量类型必须在编译期确定，并据此分配内存空间。也就是说， **每个变量的内存占用在编译阶段就已经固定下来** ，这不仅有利于提高执行效率，也使程序结构更加清晰可控。

### 2.2 整型

整型变量用于表示整数类型的数据。
C++中能够表示整型的类型有以下几种，**区别在于所占内存空间不同，进而能够表达的数字范围也是不同的**：

| **数据类型**  | **占用空间**                              | 取值范围         |
| ------------------- | ----------------------------------------------- | ---------------- |
| short(短整型)       | 2字节                                           | [-2^15 ~ 2^15-1] |
| int(整型)           | 4字节                                           | [-2^31 ~ 2^31-1] |
| long(长整形)        | Windows为4字节，Linux为4字节(32位)，8字节(64位) | [-2^31 ~ 2^31-1] |
| long long(长长整形) | 8字节                                           | [-2^63 ~ 2^63-1] |

示例代码：

```C++
int main()
{
    short shortVar = 1;
    int intVar = 655;
    long longVar = 1024;
    long long bigVar = 10000;
    return 0;
}
```

### 2.3 浮点型（实型）

浮点型变量用于表示小数。
根据占用内存空间、能够表达的小数精度（有效数字）不同，分为两种：

1. 单精度浮点型（float）
2. 双精度浮点型（double）| **数据类型** | **占用空间** | **有效数字范围** |
   | ------------------ | ------------------ | ---------------------- |
   | float              | 4字节              | 7位有效数字            |
   | double             | 8字节              | 15～16位有效数字       |

示例代码：

```C++
int main() {
    float floatVar = 3.14f;
    double doubleVar = 3.1415926;
    float floatVar2 = 1e2; // 1 * 10 ^ 2
    float floatVar3 = 1e-2; // 1 * 10 ^ -2
    return 0;
}
```

### 2.5 字符型

* 字符型变量用于表示单个字符
  * 在定义和初始化字符型变量时，需要用单引号将字符括起来
  * 单引号内只能有一个字符，不能有多个
* C/C++中，字符型变量只占**1个字节**
* 字符型变量，存储的是ASCII码（本质是一个整数）
  示例代码：

```C++
int main() {
	char ch = 'a';
    cout << ch << endl;
    cout << (int)ch << endl;  //输出字符a对应的ASCII码
	ch = 97; //可以直接用ASCII给字符型变量赋值
    //ch = "abcde"; //错误，不可以用双引号
	//ch = 'abcde'; //错误，单引号内只能引用一个字符
}
```

### 2.6 字符串型
顾名思义，字符串型变量，就是表示一个字符串
C风格的字符串示例：
```C++
int main() {
   	char str1[] = "hello world";
    const char* str2 = "hello world";
   	return 0;
}
```
C++风格的字符串示例：
```C++
#include <string>
using namespace std;
int main() {
   	string str = "hello world"; // string其实是STL中的一个类，后续讲STL时还会提到
   	return 0;
}
```

### 2.7 sizeof关键字
利用sizeof关键字可以***统计数据类型所占内存大小**
示例代码：
```C++
int main() {
	cout << "short 类型所占内存空间为： " << sizeof(short) << endl;
	cout << "int 类型所占内存空间为： " << sizeof(int) << endl;
	cout << "long 类型所占内存空间为： " << sizeof(long) << endl;
	cout << "long long 类型所占内存空间为： " << sizeof(long long) << endl;
	return 0;
}
```
