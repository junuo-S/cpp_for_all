# 06_函数
## 6.1 概述
* 函数是C++程序的基本组成部分，用于实现代码的模块化和重用。
* 通过函数，我们可以将复杂的问题分解为更小、更易管理的子问题。
* 函数定义了一个特定的任务，并且可以被多次调用，从而提高代码的可读性和维护性。
* 一个大型程序通常由多个函数组成，每个函数负责完成特定的功能。

## 6.2 函数的定义与声明
* 函数的定义包括函数名、参数列表、返回类型和函数体。
* 函数声明（或原型）用于告诉编译器函数的名称、参数类型和返回类型，通常放在函数定义之前或头文件中。
* 语法格式：
```cpp
返回类型 函数名(参数类型 参数名, ...) {
    // 函数体
}

// 返回类型：指定函数返回值的类型，如果没有返回值，使用`void`。
// 函数名：标识函数的名称，遵循标识符命名规则。
// 参数列表：列出函数接受的参数类型和名称，多个参数用逗号分隔，可以没有任何参数。
// 函数体：包含实现函数功能的代码块。
```

* 示例：
```cpp
#include <iostream>
using namespace std;
// 函数声明, 告诉编译器函数的存在以及如何调用函数, 可以声明多次
int add(int a, int b);
int main() {
    int result = add(5, 3);
    cout << "Result: " << result << endl; // 输出：Result: 8
    return 0;
}
// 函数定义，只能有一次
int add(int a, int b) {
    return a + b;
}
```

> 补充说明：
> * 在实际开发中，**声明和定义要保持完全一致**，包括函数名、参数个数与类型、返回类型、命名空间等，否则会出现链接错误或者重载解析失败。
> * 一般推荐：**对外提供的接口函数只在头文件中声明，在对应的.cpp源文件中定义**，这样可以减少重复编译、避免多重定义问题。
> * 如果函数体很短、调用频繁，可以考虑使用`inline`关键字将其声明为**内联函数**，让编译器在调用处直接展开，减少函数调用开销（但是否真正内联，由编译器最终决定）。
> * 头文件中定义的函数（尤其是模板函数、内联函数）通常需要直接写出函数体，这样其他源文件在编译时才能“看到”实现，否则模板实例化会失败。

## 6.3 函数的调用
* 函数调用是指在程序中使用函数名和参数来执行函数定义的任务。(调用定义好的函数)
* 语法格式：
```cpp
函数名(实参1, 实参2, ...);
```

* 示例：
```cpp
#include <iostream>
using namespace std;
// 形参：形参是函数定义时括号内的变量，用于接收调用时传入的值。
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 3); // 实参：实参是函数调用时传入的具体值。
    cout << "Result: " << result << endl; // 输出：Result: 8
    return 0;
}
```

> 说明：
> * 一般来说，函数调用时会在栈上为被调用函数开辟一块新的“活动记录”（栈帧），用来保存形参、局部变量等信息，调用结束后这块空间自动释放。
> * `main` 函数是程序的入口，程序从 `main` 开始执行，但 `main` 也只是一个普通函数，同样可以被其他函数调用（不推荐在工程中随意调用 `main`，这里只是说明其本质）。
> * 为了提高可读性，一个函数最好只做“一件事”，如果函数体太长、逻辑太复杂，就应该考虑拆分成多个更小的函数再在调用处组合使用。

## 6.4 函数的参数传递
* 函数参数传递有三种主要方式：值传递、引用传递、地址传递。

> 小结：
> * **值传递**更安全，函数内部无法意外修改外部变量，但会有一次拷贝开销（对内置类型通常忽略不计，对大对象可能需要注意）。
> * **引用/地址传递**可以在函数内部直接修改外部变量，也能避免不必要的拷贝，但要注意：谁有权修改数据、是否可能被意外改坏。
> * 在 C++ 中，推荐优先使用“引用”来表达输出参数或需要修改的参数，指针更多用在需要表达“可以为空”“数组/缓冲区”等语义时。

### 6.4.1 值传递
* 值传递是将实参的值复制给形参，函数内部对形参的修改不会影响实参。
* 示例：
```cpp
#include <iostream>
using namespace std;
void modifyValue(int x) {
    x = 20; // 修改形参，不影响实参
}
int main() {
    int a = 10;
    modifyValue(a);
    cout << "a: " << a << endl; // 输出：a: 10
    return 0;
}
```

### 6.4.2 引用传递
* 引用传递是将实参的引用（别名）传递给形参，函数内部对形参的修改会影响实参。
* 示例：
```cpp
#include <iostream>
using namespace std;
void modifyValue(int &x) {
    x = 20; // 修改形参，影响实参
}
int main() {
    int a = 10;
    modifyValue(a);
    cout << "a: " << a << endl; // 输出：a: 20
    return 0;
}
```

### 6.4.3 地址传递
* 地址传递是将实参的地址传递给形参，函数通过指针操作实参的值。
* 示例：
```cpp
#include <iostream>
using namespace std;
void modifyValue(int *x) {
    *x = 20; // 通过指针修改实参的值
}
int main() {
    int a = 10;
    modifyValue(&a); // 传递实参的地址
    cout << "a: " << a << endl; // 输出：a: 20
    return 0;
}
```

## 6.5 函数的返回值
* 函数可以通过返回值将结果传递回调用者。
* 使用`return`语句指定返回值，函数的返回类型必须与返回值类型匹配。
* 示例：
```cpp
#include <iostream>
using namespace std;
int add(int a, int b) {
    return a + b; // 返回两个数的和
}
int main() {
    int result = add(5, 3);
    cout << "Result: " << result << endl; // 输出：Result: 8
    return 0;
}
```

## 6.6 函数的分文件编写
* 为了提高代码的可维护性和重用性，函数通常分文件编写。
* 头文件（.h或.hpp）用于声明函数，源文件（.cpp）用于定义函数。
* 示例：
```cpp
// math_functions.h
#pragma once
int add(int a, int b);

// math_functions.cpp
#include "math_functions.h"
int add(int a, int b) {
    return a + b;
}

// main.cpp
#include <iostream>
#include "math_functions.h"
using namespace std;
int main() {
    int result = add(5, 3);
    cout << "Result: " << result << endl; // 输出：Result: 8
    return 0;
}
```

## 6.7 函数重载
* 函数重载是指在同一作用域内，可以定义多个同名但参数列表不同的函数。
* 编译器根据函数调用时传入的参数类型和数量来决定调用哪个函数。
* 示例：
```cpp
#include <iostream>
using namespace std;
int add(int a, int b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

double add(double a, double b) {
    return a + b;
}

int main() {
    cout << "Int add: " << add(5, 3) << endl;         // 调用int版本
    cout << "Int add (3 args): " << add(5, 3, 2) << endl; // 调用三个int参数版本
    cout << "Double add: " << add(5.5, 3.3) << endl; // 调用double版本
    return 0;
}
```

> 函数重载的注意事项
> * 函数名相同但参数列表必须不同（参数类型、数量或顺序）。
> * 返回类型不能作为函数重载的依据。

## 6.8 函数的默认参数和占位参数
* 默认参数是在函数声明或定义时为某些参数指定默认值，如果调用函数时没有传入这些参数，则使用默认值。
* 占位参数用于占据参数位置，但在函数体内不使用该参数。
* 默认参数示例：
```cpp
#include <iostream>
using namespace std;
// 默认参数必须从右向左依次设置
void displayInfo(string name, int age = 18, string city = "Unknown") {
    cout << "Name: " << name << ", Age: " << age << ", City: " << city << endl;
}
int main() {
    displayInfo("Alice"); // 使用默认参数age和city
    displayInfo("Bob", 25); // 使用默认参数city
    displayInfo("Charlie", 30, "New York"); // 不使用默认参数
    return 0;
}
```

* 占位参数示例：
```cpp
#include <iostream>
using namespace std;
void exampleFunction(int a, int /*b*/, int c) {
    cout << "a: " << a << ", c: " << c << endl;
}
int main() {
    exampleFunction(1, 2, 3); // b被占位，不使用
    return 0;
}
```

## 6.9 递归函数
* 递归函数是指在函数体内调用自身的函数。
* 递归函数通常需要一个基准条件来终止递归调用，防止无限递归，引发栈溢出崩溃。
* 示例：
```cpp
#include <iostream>
using namespace std;

// 求阶乘的递归函数
int factorial(int n) {
    if (n <= 1) { // 基准条件
        return 1;
    }
    return n * factorial(n - 1); // 递归调用
}
int main() {
    int num = 5;
    cout << "Factorial of " << num << " is " << factorial(num) << endl; // 输出：Factorial of 5 is 120
    return 0;
}
```

> 递归与迭代：
> * 许多问题既可以用递归写，也可以改写成 `while` / `for` 循环的迭代形式，例如阶乘、斐波那契数列、树的遍历等。
> * 递归代码通常更接近数学定义、逻辑更直观，但可能带来函数调用开销和栈深度限制；当数据规模很大或对性能要求较高时，可以考虑改写为迭代或使用显式栈模拟递归。
> * 写递归时一定要先想清楚：**1）最小子问题是什么？2）如何从更小的子问题推导出当前问题？3）何时停止递归？** 这三个问题想明白了，递归就不再神秘。
