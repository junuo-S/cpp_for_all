# 09_标准输入输出流

在写 C++ 程序时，你几乎每天都要和“输入、输出”打交道：读键盘、打印结果、输出日志、提示错误信息。  
**标准输入输出流**就是这套交互机制的核心，它不仅能让程序“会说话”，还能让程序“听懂”用户输入。

本章围绕以下几个关键点展开：

| 主题 | 说明 |
| ---- | ---- |
| `cin` | 标准输入流，默认从键盘读取 |
| `cout` | 标准输出流，默认向控制台输出 |
| `cerr` / `clog` | 标准错误流与日志流 |
| 格式控制 | 控制宽度、精度、对齐、进制等 |
| 输入陷阱 | 缓冲区、空白字符、`getline` 常见问题 |

---

## 9.1 流（stream）到底是什么

“流”可以理解成**数据流动的通道**。  
在 C++ 中，流把“读/写设备”统一抽象成对象，程序员不必关心底层硬件细节，只要通过统一接口进行操作。

最常见的标准流对象有：

- `cin`：标准输入（keyboard -> program）
- `cout`：标准输出（program -> screen）
- `cerr`：标准错误输出（program -> screen，通常不缓冲）
- `clog`：标准日志输出（program -> screen，通常有缓冲）

它们都在头文件 `iostream` 中，属于 `std` 命名空间。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello Stream!" << endl;
    return 0;
}
```

## 9.2 `cout`：最常用的输出流

### 9.2.1 基本输出

`cout` 与插入运算符 `<<` 组合使用，把数据“插入”到输出流。

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    double score = 95.5;
    char grade = 'A';
    bool pass = true;

    cout << "年龄: " << age << endl;
    cout << "成绩: " << score << endl;
    cout << "等级: " << grade << endl;
    cout << "是否通过: " << pass << endl; // bool 默认输出 1/0
    return 0;
}
```

### 9.2.2 链式输出

`<<` 支持链式写法，左到右依次输出，更紧凑。

```cpp
cout << "name=" << "Alice" << ", age=" << 18 << ", score=" << 88.5 << endl;
```

### 9.2.3 `endl` 与 `'\n'` 的区别

- `endl`：换行 + 强制刷新缓冲区；
- `'\n'`：仅换行，不强制刷新。

频繁输出时，`'\n'` 往往更高效。

```cpp
cout << "line1\n";
cout << "line2\n";
// 需要立刻刷新时再使用 endl
cout << "critical message" << endl;
```

## 9.3 `cin`：读取用户输入

### 9.3.1 基本读取规则

`cin >> 变量` 会读取一个“记号（token）”，并以空格、Tab、换行作为分隔符。

```cpp
#include <iostream>
using namespace std;

int main() {
    int id;
    double salary;
    string name;

    cout << "请输入 id salary name: ";
    cin >> id >> salary >> name;

    cout << "id=" << id << ", salary=" << salary << ", name=" << name << endl;
    return 0;
}
```

如果输入是：`1001 7999.5 ZhangSan`，则三个变量都能正确读取。  
但如果姓名输入为 `Zhang San`，`cin >> name` 只会读到 `Zhang`，后面的 `San` 会留在缓冲区。

### 9.3.2 输入失败状态

当用户输入类型不匹配时，流会进入失败状态，后续读取会直接失败。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "请输入整数: ";
    cin >> n;

    if (cin.fail()) {
        cout << "输入不是整数，读取失败。" << endl;
        return 0;
    }

    cout << "你输入的是: " << n << endl;
    return 0;
}
```

## 9.4 `getline`：读取整行文本

### 9.4.1 为什么需要 `getline`

`cin >>` 会以空白符分割，不适合读取带空格的句子。  
`getline(cin, str)` 会一直读取到换行符，更适合姓名、地址、备注等文本。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string fullName;
    cout << "请输入完整姓名: ";
    getline(cin, fullName);

    cout << "你好, " << fullName << endl;
    return 0;
}
```

### 9.4.2 `cin >>` 后紧跟 `getline` 的坑

这是初学者最常见问题：  
先用 `cin >> age` 后，回车留在缓冲区；接着 `getline` 会立刻读到这个空行。

解决方式之一：使用 `cin.ignore()` 清理换行。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age;
    string hobby;

    cout << "请输入年龄: ";
    cin >> age;

    cin.ignore(); // 忽略一个字符，通常是前一次输入留下的 '\n'

    cout << "请输入兴趣爱好(可含空格): ";
    getline(cin, hobby);

    cout << "age=" << age << ", hobby=" << hobby << endl;
    return 0;
}
```

更稳妥的写法（处理多余残留）：

```cpp
#include <iostream>
#include <limits>
using namespace std;

cin.ignore(numeric_limits<streamsize>::max(), '\n');
```

## 9.5 输入缓冲区与状态控制

标准输入流维护着状态标志位，常见的有：

- `good()`：流状态正常；
- `fail()`：格式错误或提取失败；
- `eof()`：读到文件末尾（在重定向/文件输入时常见）；
- `bad()`：严重错误（设备故障等，较少见）。

当 `fail` 后，可以这样恢复：

1. `cin.clear()`：清除错误状态；
2. `cin.ignore(...)`：丢弃错误输入行；
3. 重新读取。

```cpp
#include <iostream>
#include <limits>
using namespace std;

int main() {
    int x;
    while (true) {
        cout << "请输入整数 x: ";
        cin >> x;

        if (!cin.fail()) {
            break;
        }

        cout << "输入非法，请重新输入。" << endl;
        cin.clear();
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
    }

    cout << "最终 x = " << x << endl;
    return 0;
}
```

## 9.6 格式化输出：让结果更专业

头文件 `iomanip` 提供了很多格式控制工具。

### 9.6.1 常见控制器总览

| 控制器 | 作用 |
| ---- | ---- |
| `setw(n)` | 设置输出宽度（仅对下一次输出生效） |
| `setfill(ch)` | 设置填充字符 |
| `left` / `right` | 左对齐 / 右对齐 |
| `fixed` | 使用定点格式输出浮点数 |
| `setprecision(n)` | 设置精度（与 `fixed` 联用时表示小数位） |
| `boolalpha` | 输出 `true/false` 而不是 `1/0` |
| `hex` / `dec` / `oct` | 十六进制 / 十进制 / 八进制 |

### 9.6.2 对齐输出示例

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << left;
    cout << setw(12) << "Name" << setw(8) << "Age" << setw(10) << "Score" << '\n';
    cout << setw(12) << "Tom"  << setw(8) << 18    << setw(10) << 91.5    << '\n';
    cout << setw(12) << "Lucy" << setw(8) << 19    << setw(10) << 88.25   << '\n';
    return 0;
}
```

### 9.6.3 浮点精度示例

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.1415926535;

    cout << pi << '\n'; // 默认格式
    cout << fixed << setprecision(2) << pi << '\n'; // 3.14
    cout << fixed << setprecision(4) << pi << '\n'; // 3.1416
    return 0;
}
```

### 9.6.4 进制输出示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 255;
    cout << "dec: " << dec << n << '\n';
    cout << "hex: " << hex << n << '\n';
    cout << "oct: " << oct << n << '\n';
    return 0;
}
```

## 9.7 `cerr` 与 `clog`：错误与日志输出

很多同学只用 `cout`，但在工程代码里，区分“正常信息”和“错误信息”非常重要。

- `cout`：普通结果输出；
- `cerr`：错误输出，通常立即刷新，适合报错；
- `clog`：日志输出，通常带缓冲，适合记录运行信息。

```cpp
#include <iostream>
using namespace std;

int main() {
    int divisor = 0;

    cout << "开始计算..." << endl;
    if (divisor == 0) {
        cerr << "[ERROR] 除数不能为 0" << endl;
        return 1;
    }

    clog << "[LOG] 程序正常结束" << endl;
    return 0;
}
```

在调试和部署阶段，`cerr`/`clog` 的分流能显著提高定位问题效率。

## 9.8 链式输入输出与运算符返回值

很多人会问：为什么可以写 `cin >> a >> b >> c`，也可以写 `cout << x << y << z`？

原因是：`>>` 和 `<<` 对流的重载会返回流对象本身（引用），因此可以继续接下一个操作。  
这也意味着你可以直接把流放进条件判断：

```cpp
if (cin >> a >> b) {
    // 读取成功
} else {
    // 读取失败
}
```

示例：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "请输入两个整数: ";
    if (cin >> a >> b) {
        cout << "sum = " << (a + b) << endl;
    } else {
        cout << "输入格式错误" << endl;
    }
    return 0;
}
```

## 9.9 实战：健壮的交互式输入模板

真实项目里，输入经常不可靠。下面给出一个实用模板：  
要求用户输入年龄（1~120）和昵称（允许空格），输入非法要重复提示。

```cpp
#include <iostream>
#include <string>
#include <limits>
using namespace std;

int main() {
    int age;
    string nickname;

    while (true) {
        cout << "请输入年龄(1~120): ";
        cin >> age;

        if (cin.fail()) {
            cout << "年龄必须是整数，请重试。\n";
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            continue;
        }

        if (age < 1 || age > 120) {
            cout << "年龄超出范围，请重试。\n";
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            continue;
        }

        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        break;
    }

    cout << "请输入昵称(可包含空格): ";
    getline(cin, nickname);

    cout << "\n===== 用户信息 =====\n";
    cout << "age      : " << age << '\n';
    cout << "nickname : " << nickname << '\n';
    return 0;
}
```

这个模板体现了 3 个核心能力：

1. 格式错误恢复（`clear + ignore`）；
2. 业务范围校验（1~120）；
3. 混合输入场景处理（`>>` + `getline`）。

## 9.10 标准流与性能

在算法题或高频 I/O 程序中，你可能看到两行代码：

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

含义：

- `sync_with_stdio(false)`：取消 C 与 C++ 标准流同步，提升 C++ 流性能；
- `cin.tie(nullptr)`：解绑 `cin` 与 `cout`，避免每次输入前都刷新输出。

示例：

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, x, sum = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        sum += x;
    }
    cout << sum << '\n';
    return 0;
}
```

注意：关闭同步后，不建议混用 `scanf/printf` 与 `cin/cout`，否则顺序可能异常。

## 9.11 综合案例：简易成绩录入与统计系统

### 9.11.1 需求

- 输入学生人数 `n`；
- 逐个输入学生姓名（可含空格）和成绩；
- 成绩必须在 `0~100`，非法需重输；
- 最后输出平均分、最高分、最低分，并按表格展示。

### 9.11.2 代码实现

```cpp
#include <iostream>
#include <iomanip>
#include <string>
#include <vector>
#include <limits>
using namespace std;

struct Student {
    string name;
    double score;
};

double readScore() {
    double s;
    while (true) {
        cin >> s;
        if (cin.fail()) {
            cout << "成绩必须是数字，请重新输入: ";
            cin.clear();
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            continue;
        }
        if (s < 0 || s > 100) {
            cout << "成绩范围应为 0~100，请重新输入: ";
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            continue;
        }
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        return s;
    }
}

int main() {
    int n;
    cout << "请输入学生人数: ";
    while (!(cin >> n) || n <= 0) {
        cout << "人数必须是正整数，请重新输入: ";
        cin.clear();
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
    }
    cin.ignore(numeric_limits<streamsize>::max(), '\n');

    vector<Student> arr;
    arr.reserve(n);

    for (int i = 0; i < n; i++) {
        Student st;
        cout << "\n第 " << i + 1 << " 位学生姓名: ";
        getline(cin, st.name);

        cout << "第 " << i + 1 << " 位学生成绩: ";
        st.score = readScore();

        arr.push_back(st);
    }

    double sum = 0.0;
    int maxIdx = 0, minIdx = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i].score;
        if (arr[i].score > arr[maxIdx].score) maxIdx = i;
        if (arr[i].score < arr[minIdx].score) minIdx = i;
    }
    double avg = sum / n;

    cout << "\n========== 成绩单 ==========\n";
    cout << left << setw(6) << "序号" << setw(20) << "姓名" << setw(10) << "成绩" << '\n';
    for (int i = 0; i < n; i++) {
        cout << left << setw(6) << i + 1
             << setw(20) << arr[i].name
             << setw(10) << fixed << setprecision(2) << arr[i].score << '\n';
    }

    cout << "\n平均分: " << fixed << setprecision(2) << avg << '\n';
    cout << "最高分: " << arr[maxIdx].name << " (" << arr[maxIdx].score << ")\n";
    cout << "最低分: " << arr[minIdx].name << " (" << arr[minIdx].score << ")\n";

    return 0;
}
```

### 9.11.3 案例价值

这个案例把标准输入输出流的关键点串了起来：

- `cin` 输入校验；
- `getline` 读取带空格姓名；
- `clear/ignore` 修复错误状态；
- `iomanip` 做表格化输出；
- `cerr` 思维可扩展到异常处理与日志系统。

## 9.12 常见错误清单（高频踩坑）

1. **把 `=` 写成 `==` 或相反**  
   条件判断和赋值混淆会让输入逻辑异常。

2. **`cin >>` 与 `getline` 混用时不清缓冲区**  
   结果是 `getline` 读到空串。

3. **输入失败后不 `clear`**  
   流一直处于失败状态，后续读取全失败。

4. **过度使用 `endl`**  
   每次都刷新缓冲区，性能不必要下降。

5. **忽视输出格式一致性**  
   不做对齐和精度控制，日志/报表可读性很差。

6. **关闭同步后仍混用 C 风格 I/O**  
   容易出现输出顺序异常问题。

## 9.13 练习题（建议独立完成）

### 练习 1：多行留言板

要求：循环读取多行留言（`getline`），输入 `END` 结束；最后按序号输出所有留言。

训练点：`getline`、循环条件、字符串比较、统一输出格式。

### 练习 2：进制转换器

要求：输入一个十进制整数，同时输出它的十进制、十六进制、八进制表示。

训练点：`dec/hex/oct` 控制器、链式输出。

### 练习 3：输入容错计算器

要求：输入两个 `double` 与一个运算符（`+ - * /`），完成计算；若类型错误或除零，给出错误提示并允许重输。

训练点：`cin.fail()`、状态恢复、`cerr` 报错、分支处理。

## 9.14 小结

标准输入输出流不是“只会打印一行字”那么简单，它决定了程序与用户交互的质量。  
掌握本章后，你应该具备以下能力：

- 能熟练使用 `cin/cout` 进行基础交互；
- 能处理 `getline` 与缓冲区问题；
- 能在输入失败时进行恢复并重试；
- 能使用 `iomanip` 输出规范、可读的结果；
- 能区分普通输出、错误输出、日志输出；
- 能在性能敏感场景下合理优化 I/O。

当你继续学习文件流、字符串流、面向对象和项目开发时，这些标准流基础会直接复用。  
**把输入输出写稳、写清晰，是从“能跑”走向“可维护”的关键一步。**
