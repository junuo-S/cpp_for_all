# 类和对象（中）：对象模型、友元与运算符重载

---

上一章我们学习了封装的基本思想和对象的生命周期管理。这一章深入 C++ 对象在内存中的真实布局，并掌握两个强大的扩展机制：友元打破封装边界，运算符重载让自定义类型用起来像内置类型。

---

## 一、C++ 对象模型

### 1.1 成员变量与成员函数的存储

C++ 类中的**成员变量**和**成员函数**是分开存储的：

- **非静态成员变量**：属于每个对象，存储在对象的内存空间中。
- **成员函数**：属于整个类，存储在代码区，所有对象共享同一份。

```cpp
#include <iostream>
using namespace std;

class Demo {
    int x;           // 非静态成员变量——占对象空间
    int y;

    void func() { }  // 成员函数——存在代码区，不占对象空间
    static int s;    // 静态成员变量——存在全局区
};

int main() {
    cout << sizeof(Demo) << endl;   // 输出 8（两个 int）
    return 0;
}
```

理解这个模型很重要——它解释了为什么 `this` 指针是必要的，以及为什么静态成员函数不能访问非静态成员。

### 1.2 空类的大小

一个没有任何成员的类的大小是多少？

```cpp
#include <iostream>
using namespace std;

class Empty { };

int main() {
    cout << "sizeof(Empty) = " << sizeof(Empty) << endl;
    return 0;
}
```

输出通常是 `1`。原因是 C++ 标准要求**同一个类型的两个不同对象必须有不同的地址**。编译器给空类"塞入"了一个 1 字节的占位符。

### 1.3 成员函数的"隐藏"机制

从汇编层面看，成员函数其实就是一个普通函数，只不过编译器在参数列表最前面**隐式**添加了一个 `this` 指针。

```cpp
class Calc {
public:
    int value;
    void add(int n) { value += n; }
};

// 编译器本质上将它转换为：
// void add(Calc* this, int n) { this->value += n; }
```

每个对象调用成员函数时，把自己的地址作为 `this` 传入。这就是"不同的对象调用同一个成员函数，操作的是各自的数据"的原因。

### 1.4 内存对齐与 sizeof

编译器为了 CPU 访问效率，会在成员变量之间插入填充字节（padding），这是 `sizeof` 值往往大于成员大小之和的原因。

```cpp
#include <iostream>
using namespace std;

class Packed {
    char  a;   // 1 字节，偏移 0
    int   b;   // 4 字节，对齐到 4 的倍数 -> 偏移 4，a 后填充 3 字节
    short c;   // 2 字节，对齐到 2 的倍数 -> 偏移 8
               // 总大小：10，对齐到最大成员（4）的倍数 -> 12
};

int main() {
    cout << sizeof(Packed) << endl;    // 通常输出 12
    return 0;
}
```

> 调整成员的声明顺序可以减小 padding 浪费。通常把大的成员放在前面，小的放后面。

## 二、this 指针

### 2.1 this 的本质

`this` 是一个**指针常量**（`Type* const this`），指向当前调用成员函数的对象。

```cpp
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;

    void set(int x, int y) {
        this->x = x;    // 形参名与成员名相同，用 this 区分
        this->y = y;
    }

    Point* self() {
        return this;
    }
};

int main() {
    Point p;
    p.set(3, 4);
    cout << p.x << "," << p.y << endl;
    cout << (p.self() == &p) << endl;  // 1 (true)
    return 0;
}
```

### 2.2 链式调用

这是 `this` 最重要的用法之一——成员函数返回 `*this`，让调用可以串联起来。

```cpp
#include <iostream>
using namespace std;

class StringBuilder {
public:
    StringBuilder& append(const string& s) {
        buffer += s;
        return *this;
    }

    StringBuilder& newline() {
        buffer += "\n";
        return *this;
    }

    void print() const { cout << buffer << endl; }

private:
    string buffer;
};

int main() {
    StringBuilder sb;
    sb.append("Hello").append(", ").append("World").newline()
      .append("This is a chain!").newline();
    sb.print();
    return 0;
}
```

### 2.3 空指针调用成员函数的陷阱

如果用一个空指针调用成员函数，而函数内部没有访问成员变量，程序可能正常运行——**但这属于未定义行为**，绝对不能依赖。

```cpp
#include <iostream>
using namespace std;

class Test {
public:
    void func1() { cout << "func1" << endl; }  // 不访问成员，可能不崩溃

    void func2() {
        cout << "func2, value = " << value << endl;  // 访问了成员，一定崩溃
    }

private:
    int value = 100;
};

int main() {
    Test* p = nullptr;
    p->func1();   // 未定义行为！不要这样写
    return 0;
}
```

## 三、const 修饰成员

### 3.1 常成员函数

在成员函数后面加 `const`，表示这个函数**不会修改对象的状态**。

```cpp
class Rectangle {
public:
    Rectangle(int w, int h) : width(w), height(h) { }

    int area() const { return width * height; }   // 常成员函数

    void resize(int w, int h) { width = w; height = h; }

private:
    int width, height;
};

int main() {
    const Rectangle r(3, 4);
    // r.resize(5, 6);         // 错误！常对象只能调用常成员函数
    cout << r.area() << endl;  // 正确

    Rectangle r2(5, 6);
    r2.resize(7, 8);
    cout << r2.area() << endl;
    return 0;
}
```

### 3.2 mutable

`mutable` 关键字允许在常成员函数中修改该成员。

```cpp
#include <iostream>
using namespace std;

class DataProcessor {
public:
    DataProcessor(int v) : data(v) { }

    int getData() const {
        ++accessCount;              // mutable 成员，可在 const 函数中修改
        return data;
    }

    int getAccessCount() const { return accessCount; }

private:
    int data;
    mutable int accessCount = 0;
};

int main() {
    const DataProcessor dp(42);
    cout << dp.getData() << endl;
    cout << dp.getData() << endl;
    cout << "访问次数：" << dp.getAccessCount() << endl;  // 2
    return 0;
}
```

## 四、static 成员

### 4.1 静态成员变量

静态成员变量**属于整个类，而非单个对象**。所有对象共享同一份数据。

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    Student(const string& name) : m_name(name) {
        ++s_count;
    }

    ~Student() { --s_count; }

    static int getCount() { return s_count; }

private:
    string m_name;
    static int s_count;   // 声明
};

int Student::s_count = 0;   // 定义并初始化

int main() {
    cout << Student::getCount() << endl;  // 0

    Student s1("张三");
    Student s2("李四");
    cout << Student::getCount() << endl;  // 2

    {
        Student s3("王五");
        cout << Student::getCount() << endl;  // 3
    }

    cout << Student::getCount() << endl;      // 2
    return 0;
}
```

**要点**：在类内声明，在类外定义并初始化。所有对象共享同一份。

### 4.2 静态成员函数

- 静态成员函数**没有 `this` 指针**，因此不能访问非静态成员。
- 只能访问静态成员变量和其他静态成员函数。

```cpp
class Logger {
public:
    static void log(const string& msg) {
        cout << "[LOG] " << msg << endl;
    }

    static void setLevel(int lv) { s_level = lv; }

private:
    static int s_level;
    int instanceId;     // 非静态——静态成员函数不能访问
};

int Logger::s_level = 0;

int main() {
    Logger::log("Program started");
    Logger::setLevel(2);
    return 0;
}
```

## 五、友元

### 5.1 为什么需要友元

封装把数据藏起来了，这是好事。但有些时候，两个类之间的关系非常紧密，比如一个"管理器"类需要访问另一个"内部数据"类的私有成员。C++ 提供了**友元（friend）**机制——允许特定的函数或类访问当前类的私有成员。

> 友元是对封装的"破例"，只在必要时使用，不要滥用。

### 5.2 友元函数

将一个普通函数声明为类的友元，该函数可以访问类的私有成员。

```cpp
#include <iostream>
using namespace std;

class Vector2D {
    friend Vector2D operator+(const Vector2D& a, const Vector2D& b);

public:
    Vector2D(double xv, double yv) : x(xv), y(yv) { }

    void print() const {
        cout << "(" << x << ", " << y << ")" << endl;
    }

private:
    double x, y;
};

Vector2D operator+(const Vector2D& a, const Vector2D& b) {
    return Vector2D(a.x + b.x, a.y + b.y);
}

int main() {
    Vector2D v1(1.0, 2.0);
    Vector2D v2(3.0, 4.0);
    Vector2D v3 = v1 + v2;
    v3.print();    // (4, 6)
    return 0;
}
```

### 5.3 友元类

将整个类声明为友元，则友元类的所有成员函数都可以访问当前类的私有成员。

```cpp
#include <iostream>
using namespace std;

class Engine {
    friend class Car;

public:
    Engine() : horsepower(0) { }

private:
    int horsepower;
    void startInternal() {
        cout << "Engine internal start" << endl;
    }
};

class Car {
public:
    void setEngineHp(Engine& e, int hp) {
        e.horsepower = hp;         // 可以访问私有成员
    }

    void start(Engine& e) {
        e.startInternal();         // 可以调用私有函数
        cout << "Car is ready!" << endl;
    }
};

int main() {
    Engine e;
    Car car;
    car.setEngineHp(e, 200);
    car.start(e);
    return 0;
}
```

### 5.4 友元成员函数

如果只想让某个类的**某个特定成员函数**成为友元：

```cpp
class B;   // 前向声明

class A {
public:
    void visitB(const B& b);
};

class B {
    friend void A::visitB(const B& b);

public:
    B(int v) : secret(v) { }

private:
    int secret;
};

void A::visitB(const B& b) {
    cout << "B's secret: " << b.secret << endl;
}

int main() {
    A a;
    B b(42);
    a.visitB(b);   // B's secret: 42
    return 0;
}
```

### 5.5 友元的注意事项

1. **友元关系不能传递**：A 是 B 的友元，B 是 C 的友元，不等价于 A 是 C 的友元。
2. **友元关系不能继承**：基类的友元不是派生类的友元。
3. **友元没有对称性**：A 声明 B 是友元，但 A 不一定是 B 的友元。
4. **友元破坏了封装**：只在类之间关系极其紧密时使用。

## 六、运算符重载

运算符重载让用户自定义类型可以使用 C++ 内置的运算符语法，使代码更自然。

### 6.1 基本语法

重载方式有两种：**成员函数**或**全局函数**。后者常用于左操作数不是当前类对象的场景。

```cpp
#include <iostream>
using namespace std;

class Complex {
public:
    Complex(double r, double i) : real(r), imag(i) { }

    Complex operator+(const Complex& rhs) const {
        return Complex(real + rhs.real, imag + rhs.imag);
    }

    Complex& operator+=(const Complex& rhs) {
        real += rhs.real;
        imag += rhs.imag;
        return *this;
    }

    bool operator==(const Complex& rhs) const {
        return real == rhs.real && imag == rhs.imag;
    }

    void print() const {
        cout << real << " + " << imag << "i" << endl;
    }

private:
    double real, imag;
};

int main() {
    Complex a(1, 2), b(3, 4);
    Complex c = a + b;
    c.print();               // 4 + 6i

    a += b;
    a.print();               // 4 + 6i

    cout << (a == c) << endl; // 1 (true)
    return 0;
}
```

### 6.2 不能重载的运算符

| 符号 | 名称 | 原因 |
|------|------|------|
| `::` | 作用域解析 | 操作的是类型/命名空间，而非表达式 |
| `.` | 成员访问 | 保护成员访问语义 |
| `.*` | 成员指针访问 | 同上 |
| `?:` | 三目运算符 | 无法模拟短路求值 |
| `sizeof` | 大小运算符 | 语言内置 |
| `typeid` | 类型信息 | 语言内置 |

### 6.3 输入输出运算符重载（<< 和 >>）

输出运算符 `<<` 和输入运算符 `>>` **必须用全局函数重载**，因为左操作数是 `ostream` / `istream`，不是当前类的对象。

```cpp
#include <iostream>
using namespace std;

class Point {
    friend ostream& operator<<(ostream& os, const Point& p);
    friend istream& operator>>(istream& is, Point& p);

public:
    Point(int xv = 0, int yv = 0) : x(xv), y(yv) { }

private:
    int x, y;
};

ostream& operator<<(ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

istream& operator>>(istream& is, Point& p) {
    is >> p.x >> p.y;
    return is;
}

int main() {
    Point p1(3, 5);
    cout << "p1 = " << p1 << endl;   // p1 = (3, 5)

    cout << "请输入 x 和 y：";
    Point p2;
    cin >> p2;
    cout << "p2 = " << p2 << endl;

    return 0;
}
```

### 6.4 自增自减运算符（++ 和 --）

前置返回引用，后置返回原值。通过一个 `int` 占位参数区分。

```cpp
#include <iostream>
using namespace std;

class Counter {
public:
    Counter(int v = 0) : value(v) { }

    Counter& operator++() {        // 前置 ++
        ++value;
        return *this;
    }

    Counter operator++(int) {      // 后置 ++
        Counter old = *this;
        ++value;
        return old;
    }

    friend ostream& operator<<(ostream& os, const Counter& c);

private:
    int value;
};

ostream& operator<<(ostream& os, const Counter& c) {
    os << c.value;
    return os;
}

int main() {
    Counter c(5);
    cout << ++c << endl;    // 6
    cout << c++ << endl;    // 6（输出旧值）
    cout << c << endl;      // 7

    ++++c;                  // 前置可以连用
    cout << c << endl;      // 9
    return 0;
}
```

### 6.5 下标运算符 []

下标运算符用于让对象像数组一样支持随机访问，通常提供 const 和非 const 两个版本。

```cpp
#include <iostream>
#include <cassert>
using namespace std;

class IntVector {
public:
    IntVector() : size(0) { }

    void push_back(int v) {
        if (size < 100) data[size++] = v;
    }

    int& operator[](int index) {
        assert(index >= 0 && index < size);
        return data[index];
    }

    const int& operator[](int index) const {
        assert(index >= 0 && index < size);
        return data[index];
    }

    int getSize() const { return size; }

private:
    int data[100];
    int size;
};

int main() {
    IntVector v;
    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    v[1] = 99;
    cout << v[1] << endl;   // 99

    for (int i = 0; i < v.getSize(); ++i)
        cout << v[i] << " ";  // 10 99 30
    cout << endl;

    return 0;
}
```

### 6.6 函数调用运算符 ()

让对象像函数一样可以被调用——这样的对象称为**函数对象（Functor）**。

```cpp
#include <iostream>
using namespace std;

class Adder {
public:
    Adder(int n) : delta(n) { }

    int operator()(int x) const { return x + delta; }

private:
    int delta;
};

int main() {
    Adder add5(5);
    Adder add10(10);

    cout << add5(3) << endl;   // 8
    cout << add10(3) << endl;  // 13

    int arr[] = {1, 2, 3, 4, 5};
    for (int& n : arr) n = add10(n);
    for (int n : arr) cout << n << " ";   // 11 12 13 14 15
    cout << endl;

    return 0;
}
```

## 七、综合案例：二维矩阵

综合运用本章的运算符重载，实现一个 2x2 矩阵类。

```cpp
#include <iostream>
using namespace std;

class Matrix2x2 {
    friend ostream& operator<<(ostream& os, const Matrix2x2& m);

public:
    Matrix2x2(double a00 = 0, double a01 = 0,
              double a10 = 0, double a11 = 0) {
        data[0][0] = a00; data[0][1] = a01;
        data[1][0] = a10; data[1][1] = a11;
    }

    double* operator[](int row) { return data[row]; }
    const double* operator[](int row) const { return data[row]; }

    Matrix2x2 operator+(const Matrix2x2& rhs) const {
        Matrix2x2 r;
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                r[i][j] = data[i][j] + rhs.data[i][j];
        return r;
    }

    Matrix2x2 operator*(const Matrix2x2& rhs) const {
        Matrix2x2 r;
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                for (int k = 0; k < 2; ++k)
                    r[i][j] += data[i][k] * rhs.data[k][j];
        return r;
    }

    bool operator==(const Matrix2x2& rhs) const {
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                if (data[i][j] != rhs.data[i][j])
                    return false;
        return true;
    }

private:
    double data[2][2];
};

ostream& operator<<(ostream& os, const Matrix2x2& m) {
    os << "[ " << m.data[0][0] << " " << m.data[0][1] << " ]\n";
    os << "[ " << m.data[1][0] << " " << m.data[1][1] << " ]";
    return os;
}

int main() {
    Matrix2x2 A(1, 2, 3, 4);
    Matrix2x2 B(5, 6, 7, 8);

    cout << "A =\n" << A << "\n\n";
    cout << "B =\n" << B << "\n\n";

    cout << "A + B =\n" << (A + B) << "\n\n";
    cout << "A * B =\n" << (A * B) << "\n\n";

    cout << "A == A: " << (A == A) << endl;   // 1
    cout << "A == B: " << (A == B) << endl;   // 0

    A[0][0] = 99;
    cout << "修改后 A[0][0] = " << A[0][0] << endl;

    return 0;
}
```

## 本章小结

| 要点 | 说明 |
|------|------|
| **对象模型** | 非静态成员变量在对象内，成员函数在代码区共享 |
| **内存对齐** | 编译器在成员间插入 padding 保证访问效率 |
| **this 指针** | 指向当前对象的指针常量，用于区分同名成员和链式调用 |
| **const 成员** | 常成员函数不修改对象；mutable 允许破例 |
| **static 成员** | 属于整个类，所有对象共享；类外定义并初始化 |
| **友元** | 函数、类、成员函数三种友元方式，破坏封装的"后门" |
| **运算符重载** | 成员函数或全局函数实现；<< >> 必须全局；++ 前后置用 int 区分 |
