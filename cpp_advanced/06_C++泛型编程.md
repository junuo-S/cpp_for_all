# 06 C++泛型编程

## 一、泛型编程概述

### 1.1 什么是泛型编程

泛型编程（Generic Programming）是一种编程范式，其核心思想是：**将算法与数据类型分离**，使得同一套代码能够作用于不同的数据类型上。C++中的模板（Template）是泛型编程的核心实现机制。

在日常生活中，我们经常见到"泛型"的思想：一个通用的充电器接口可以给不同品牌的手机充电；一个标准的螺丝刀头可以匹配多种规格的螺丝。C++的模板就如同这些"通用接口"，让函数和类不再绑死在具体的数据类型上。

### 1.2 为什么需要泛型编程

假设我们需要编写一个交换两个变量值的函数。如果不使用模板，针对不同的数据类型，我们需要编写多个重载版本：

```cpp
void SwapInt(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

void SwapDouble(double &a, double &b) {
    double temp = a;
    a = b;
    b = temp;
}

void SwapChar(char &a, char &b) {
    char temp = a;
    a = b;
    b = temp;
}
```

这段代码存在明显的问题：
- **代码冗余**：核心逻辑完全相同，只是类型不同
- **维护困难**：新增一种类型就要新增一个函数
- **易出错**：大量重复代码增加了出错概率

泛型编程通过模板机制完美解决了上述问题。使用模板，上面的三个函数可以合并为一个。

### 1.3 模板的分类

C++的模板主要分为两大类：

| 模板类别 | 作用对象 | 典型应用 |
|---------|---------|---------|
| 函数模板（Function Template） | 函数 | 通用算法、工具函数 |
| 类模板（Class Template） | 类 | 通用容器、抽象数据类型 |

两种模板的语法相似，但在使用方式和灵活性上存在诸多区别，下面将逐一详解。

## 二、函数模板

### 2.1 函数模板的定义

函数模板是一种特殊的函数声明方式，它使用**类型参数化**技术，将函数的返回值类型和参数类型抽象为模板参数。

#### 2.1.1 基本语法

函数模板的定义以关键字 `template` 开头，后跟尖括号包裹的模板参数列表，之后是普通的函数声明或定义：

```cpp
template <typename T>
T Max(T a, T b) {
    return (a > b) ? a : b;
}
```

**语法解读：**

- `template` —— 声明这是一个模板
- `typename T` —— 定义类型参数，`typename` 表示 T 是一个数据类型，也可以用 `class` 关键字代替
- `T` —— 模板参数名，代表一个通用的数据类型，通常用大写字母表示

> **注意**：在函数模板中，`typename` 和 `class` 完全等价，没有区别。但在类模板中，`class` 更为常见。历史原因：在 `typename` 被引入 C++ 之前，`class` 就已经被用来声明模板参数了。

#### 2.1.2 多类型参数

函数模板可以接受多个类型参数：

```cpp
template <typename T1, typename T2>
void PrintPair(T1 first, T2 second) {
    std::cout << "(" << first << ", " << second << ")" << std::endl;
}
```

这样，当我们需要处理不同类型组合的数据时，无需为每种组合单独编写函数。

### 2.2 函数模板的实例化

函数模板本身并不是一个真正的函数，它只是一个"蓝图"。编译器会根据实际调用时传入的参数类型，**生成**对应类型的真实函数。这个过程称为**模板实例化**（Template Instantiation）。

#### 2.2.1 隐式实例化（自动类型推导）

编译器通过函数调用时传入的实参类型，自动推导出模板参数 T 的具体类型：

```cpp
#include <iostream>

template <typename T>
T Max(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    int x = 10, y = 20;
    std::cout << Max(x, y) << std::endl;  // T 被推导为 int

    double m = 3.14, n = 2.72;
    std::cout << Max(m, n) << std::endl;  // T 被推导为 double

    char c1 = 'A', c2 = 'B';
    std::cout << Max(c1, c2) << std::endl;  // T 被推导为 char

    return 0;
}
```

当编译器遇到 `Max(x, y)` 时，发现 x 和 y 都是 int 类型，于是自动将 T 替换为 int，生成一个 `int Max(int, int)` 的实例。

#### 2.2.2 显式实例化（指定类型参数）

我们也可以显式地指定模板参数的类型，使用尖括号语法：

```cpp
int main() {
    int a = 10;
    double b = 3.14;

    // 显式指定 T 为 double
    std::cout << Max<double>(a, b) << std::endl;

    // 显式指定 T 为 int（注意：会进行截断）
    std::cout << Max<int>(a, b) << std::endl;

    return 0;
}
```

**显式实例化的优势：**
- 可以解决自动类型推导无法处理的情况（如参数类型不一致）
- 可以强制类型转换，控制模板的实例化行为
- 使代码意图更加明确

#### 2.2.3 隐式实例化与显式实例化的对比

| 对比维度 | 隐式实例化 | 显式实例化 |
|---------|-----------|-----------|
| 类型推导 | 编译器自动推导 | 程序员指定 |
| 隐式类型转换 | 不支持 | 支持 |
| 参数类型不一致 | 无法推导，编译错误 | 可以正确处理 |
| 代码可读性 | 简洁 | 意图明确，但稍显冗长 |

### 2.3 函数模板的重载

函数模板支持重载，包括**模板之间的重载**以及**模板与普通函数之间的重载**。

#### 2.3.1 模板与普通函数的重载

当函数模板与同名的普通函数并存时，编译器遵循以下调用规则：

```cpp
#include <iostream>

// 普通函数
void Display(int a) {
    std::cout << "普通函数: " << a << std::endl;
}

// 函数模板
template <typename T>
void Display(T a) {
    std::cout << "函数模板: " << a << std::endl;
}

int main() {
    Display(10);      // 调用普通函数（优先匹配）
    Display(3.14);    // 调用函数模板（普通函数需要类型转换，模板完美匹配）
    Display<>('A');   // 通过空模板参数列表，强制调用函数模板
    Display<int>(20); // 显式指定模板参数，调用函数模板

    return 0;
}
```

**调用规则总结：**

1. **优先调用普通函数**：如果普通函数恰好匹配参数类型，编译器优先选择普通函数
2. **空模板参数列表强制调用模板**：在函数名后加 `<>` 可以强制调用模板版本
3. **最佳匹配优先**：如果模板能产生更好的匹配（无需类型转换），则优先调用模板
4. **普通函数不存在时调用模板**：如果只有模板可用，则调用模板

#### 2.3.2 模板之间的重载

函数模板之间也可以重载，只要模板参数列表或函数参数列表不同即可：

```cpp
#include <iostream>

// 单参数模板
template <typename T>
void Process(T value) {
    std::cout << "单参数: " << value << std::endl;
}

// 双参数模板（重载版本）
template <typename T1, typename T2>
void Process(T1 first, T2 second) {
    std::cout << "双参数: " << first << ", " << second << std::endl;
}

// 三个参数模板（重载版本）
template <typename T>
void Process(T a, T b, T c) {
    std::cout << "三参数: " << a << ", " << b << ", " << c << std::endl;
}

int main() {
    Process(42);                 // 调用单参数版本
    Process(10, 20.5);           // 调用双参数版本
    Process(1, 2, 3);            // 调用三参数版本

    return 0;
}
```

### 2.4 函数模板的特化

虽然函数模板可以处理大多数数据类型，但某些特殊类型可能需要特殊的处理逻辑。这时候就需要使用**模板特化**（Template Specialization），也称为**具体化**。

#### 2.4.1 为什么需要特化

考虑下面这个比较函数模板：

```cpp
template <typename T>
bool Equal(T a, T b) {
    return a == b;
}
```

对于基本类型（int、double、char 等），这个模板工作得很好。但如果传入的是自定义的类对象，而该类没有重载 `==` 运算符，编译就会失败。

#### 2.4.2 显式特化

我们可以为特定类型提供专门的实现版本：

```cpp
#include <iostream>
#include <string>

// 自定义类
class Point {
public:
    Point(int x, int y) : m_x(x), m_y(y) {}

    int GetX() const { return m_x; }
    int GetY() const { return m_y; }

private:
    int m_x;
    int m_y;
};

// 通用函数模板
template <typename T>
bool Equal(T a, T b) {
    std::cout << "使用通用模板: ";
    return a == b;
}

// 为 Point 类型提供的特化版本
template <>
bool Equal<Point>(Point a, Point b) {
    std::cout << "使用 Point 特化版本: ";
    return (a.GetX() == b.GetX()) && (a.GetY() == b.GetY());
}

int main() {
    int a = 10, b = 10;
    std::cout << "Equal(a, b): " << Equal(a, b) << std::endl;

    Point p1(3, 4), p2(3, 4);
    std::cout << "Equal(p1, p2): " << Equal(p1, p2) << std::endl;

    return 0;
}
```

**特化的语法要点：**
- 以 `template <>` 开头（空的模板参数列表）
- 函数名后跟 `<Type>` 指明为哪个类型特化
- 特化版本的优先级高于通用版本

### 2.5 函数模板的局限性及应对

#### 2.5.1 常见局限性

函数模板并非万能，以下场景中通用模板可能失效：

**场景一：数组参数**
```cpp
template <typename T>
void Assign(T &a, const T &b) {
    a = b;
}
```
当 T 被推导为数组类型时，数组无法直接赋值。

**场景二：运算符不支持**
```cpp
template <typename T>
T Max(T a, T b) {
    return (a > b) ? a : b;
}
```
如果 T 是某个未重载 `>` 运算符的类，将无法编译。

**场景三：指针类型**
```cpp
template <typename T>
void PrintArray(T arr[], int size) {
    for (int i = 0; i < size; i++) {
        std::cout << arr[i] << " ";  // 需要对每种元素类型有输出能力
    }
}
```

#### 2.5.2 解决方案

1. **模板特化**：为特定类型提供专用的实现
2. **运算符重载**：在自定义类型中重载必要的运算符
3. **使用函数对象**：将运算符行为参数化

## 三、类模板

### 3.1 类模板的定义

类模板与函数模板类似，允许将类的成员数据类型参数化。它适用于需要存储或操作多种数据类型的容器类。

#### 3.1.1 基本语法

```cpp
template <typename T>
class Box {
private:
    T m_value;

public:
    Box(T value) : m_value(value) {}

    void SetValue(T value) {
        m_value = value;
    }

    T GetValue() const {
        return m_value;
    }
};
```

#### 3.1.2 多参数类模板

类模板可以有多个类型参数，实用的数据类型往往需要组合多种类型：

```cpp
#include <iostream>
#include <string>

template <typename K, typename V>
class KeyValuePair {
private:
    K m_key;
    V m_value;

public:
    KeyValuePair(K key, V value) : m_key(key), m_value(value) {}

    K GetKey() const { return m_key; }
    V GetValue() const { return m_value; }

    void Display() const {
        std::cout << "[" << m_key << "] = " << m_value << std::endl;
    }
};

int main() {
    KeyValuePair<int, std::string> kv1(1, "Alice");
    KeyValuePair<std::string, double> kv2("pi", 3.14159);

    kv1.Display();
    kv2.Display();

    return 0;
}
```

### 3.2 类模板的成员函数

类模板的成员函数具有一个重要的特性：**只有被实际调用时才会被实例化**。这意味着即使模板参数类型不支持某些操作，只要代码不调用对应的成员函数，就不会引发编译错误。

```cpp
#include <iostream>
#include <string>

template <typename T>
class Container {
private:
    T m_data;

public:
    Container(T data) : m_data(data) {}

    T GetData() const {
        return m_data;
    }

    // 这个函数只有被调用时才会检查是否支持 >
    bool IsGreaterThan(const Container &other) const {
        return m_data > other.m_data;
    }
};

class Student {
private:
    std::string m_name;
public:
    Student(const std::string &name) : m_name(name) {}
    std::string GetName() const { return m_name; }
    // 注意：Student 没有重载 > 运算符
};

int main() {
    Container<int> ci(100);
    Container<double> cd(3.14);

    // 只要不调用 IsGreaterThan，即使 T 不支持 > 也没问题
    Container<Student> cs(Student("Tom"));
    std::cout << cs.GetData().GetName() << std::endl;

    // 下面的代码无法编译（Student 未重载 >）
    // bool result = cs.IsGreaterThan(Container<Student>(Student("Jerry")));

    // int 版本没问题
    std::cout << ci.IsGreaterThan(Container<int>(50)) << std::endl;

    return 0;
}
```

这一特性称为**延迟实例化**（Lazy Instantiation），它使得类模板更加灵活。

### 3.3 类模板的实例化

与函数模板不同，**类模板没有自动类型推导功能**，必须显式指定模板参数类型：

```cpp
// 正确：显式指定类型
Box<int> intBox(42);
Box<std::string> strBox("Hello");

// 错误：类模板不支持自动类型推导
// Box wrongBox(42);  // 编译错误！
```

#### 3.3.1 默认模板参数

类模板支持为模板参数指定默认值，这也是类模板区别于函数模板的一个重要特点：

```cpp
#include <iostream>
#include <string>

template <typename T = int>  // 默认类型为 int
class DataHolder {
private:
    T m_data;

public:
    DataHolder(T data) : m_data(data) {}

    void Display() const {
        std::cout << "数据: " << m_data << std::endl;
    }
};

int main() {
    DataHolder<> defaultData(100);     // 使用默认类型 int
    DataHolder<double> floatData(3.14); // 显式指定为 double

    defaultData.Display();
    floatData.Display();

    return 0;
}
```

> **注意**：默认模板参数只能出现在类模板中，函数模板不支持默认模板参数（C++11 之前。按题目要求，不讲现代 C++，因此我们只说函数模板不支持默认参数。）

### 3.4 类模板的特化

与函数模板类似，类模板也支持特化，而且类模板还支持**偏特化**（Partial Specialization），这是类模板特化独有的能力。

#### 3.4.1 全特化

全特化为特定的类型提供完整的实现，与函数模板的特化类似：

```cpp
#include <iostream>
#include <cstring>

// 通用类模板
template <typename T>
class Comparator {
public:
    static bool Equal(const T &a, const T &b) {
        return a == b;
    }
};

// 全特化：为 const char* 提供专门的实现
template <>
class Comparator<const char*> {
public:
    static bool Equal(const char *a, const char *b) {
        return std::strcmp(a, b) == 0;
    }
};

int main() {
    int x = 5, y = 5;
    std::cout << Comparator<int>::Equal(x, y) << std::endl;  // 1

    const char *s1 = "hello";
    const char *s2 = "hello";
    // 如果不特化，这里会比较指针地址而非字符串内容
    std::cout << Comparator<const char*>::Equal(s1, s2) << std::endl;  // 1

    return 0;
}
```

#### 3.4.2 偏特化

偏特化是类模板独有的强大特性，它允许对**部分模板参数**或**特定类别**进行特化：

**1. 对部分参数特化：**

```cpp
#include <iostream>

template <typename T1, typename T2>
class Printer {
public:
    static void Print(const T1 &a, const T2 &b) {
        std::cout << "通用版本: " << a << ", " << b << std::endl;
    }
};

// 偏特化：当第二个类型为 int 时
template <typename T1>
class Printer<T1, int> {
public:
    static void Print(const T1 &a, const int &b) {
        std::cout << "偏特化版本(int): " << a << " 和整数 " << b << std::endl;
    }
};

int main() {
    Printer<double, double>::Print(3.14, 2.72);  // 通用版本
    Printer<std::string, int>::Print("年龄", 25); // 偏特化版本

    return 0;
}
```

**2. 对指针类型偏特化：**

```cpp
#include <iostream>

template <typename T>
class Wrapper {
public:
    static void Describe(const T &value) {
        std::cout << "值: " << value << std::endl;
    }
};

// 偏特化：当 T 是指针时
template <typename T>
class Wrapper<T*> {
public:
    static void Describe(T *ptr) {
        if (ptr) {
            std::cout << "指针指向的值: " << *ptr << " (地址: " << ptr << ")" << std::endl;
        } else {
            std::cout << "空指针" << std::endl;
        }
    }
};

int main() {
    int num = 42;
    Wrapper<int>::Describe(num);     // 通用版本
    Wrapper<int*>::Describe(&num);   // 指针偏特化版本

    return 0;
}
```

### 3.5 类模板的继承

类模板可以参与继承体系，有以下几种常见模式：

#### 3.5.1 普通类继承类模板的实例

```cpp
template <typename T>
class Base {
protected:
    T m_value;

public:
    Base(T val) : m_value(val) {}
    T GetValue() const { return m_value; }
};

// 普通类继承某个具体实例
class IntDerived : public Base<int> {
public:
    IntDerived(int val) : Base<int>(val) {}

    void Show() const {
        std::cout << "整数值: " << GetValue() << std::endl;
    }
};
```

#### 3.5.2 类模板继承类模板

```cpp
template <typename T>
class Base {
protected:
    T m_data;
public:
    Base(T data) : m_data(data) {}
};

// 子类也是类模板，继承自 Base<T>
template <typename T>
class Derived : public Base<T> {
public:
    Derived(T data) : Base<T>(data) {}

    T GetDoubleData() const {
        // 注意：在继承的类模板中访问基类成员，需要使用 this-> 或 Base<T>::
        return this->m_data * 2;
    }
};
```

> **重要提示**：在继承的类模板中访问基类的成员时，不能直接使用成员名，而应使用 `this->` 或 `Base<T>::` 来显式限定。这是因为编译器在模板的两阶段查找中，不会在依赖的基类中查找未限定的名称。

## 四、非类型模板参数

模板参数不一定是类型，也可以是**非类型**的常量值，如整数、枚举、指针或引用。

### 4.1 基本用法

```cpp
#include <iostream>

// N 是一个非类型模板参数，代表数组大小
template <typename T, int N>
class FixedArray {
private:
    T m_data[N];

public:
    int GetSize() const {
        return N;
    }

    void Set(int index, T value) {
        if (index >= 0 && index < N) {
            m_data[index] = value;
        }
    }

    T Get(int index) const {
        if (index >= 0 && index < N) {
            return m_data[index];
        }
        return T();  // 越界时返回默认值
    }
};

int main() {
    FixedArray<int, 5> intArray;   // 5 个整数的数组
    FixedArray<double, 10> dblArray; // 10 个 double 的数组

    std::cout << "intArray 大小: " << intArray.GetSize() << std::endl;
    std::cout << "dblArray 大小: " << dblArray.GetSize() << std::endl;

    intArray.Set(0, 100);
    intArray.Set(1, 200);
    std::cout << "intArray[0]: " << intArray.Get(0) << std::endl;

    return 0;
}
```

### 4.2 非类型参数的限制

非类型模板参数必须是**编译期常量**（编译时就能确定的值），不能是运行时变量：

```cpp
template <int N>
class Buffer {
    char m_buf[N];
};

int main() {
    Buffer<256> buf1;      // 正确：256 是编译期常量
    Buffer<1 + 2> buf2;    // 正确：常量表达式

    int size = 100;
    // Buffer<size> buf3;  // 错误：size 不是编译期常量

    const int constSize = 100;
    Buffer<constSize> buf4; // 正确：const 常量

    return 0;
}
```

## 五、模板的友元

类模板中的友元关系比较复杂，需要区分几种情况。

### 5.1 非模板友元函数

```cpp
#include <iostream>

template <typename T>
class Point {
private:
    T m_x;
    T m_y;

    // 声明一个非模板函数为友元
    friend void ShowPoint(const Point<int> &p);

public:
    Point(T x, T y) : m_x(x), m_y(y) {}
};

// 只能访问 Point<int> 的私有成员
void ShowPoint(const Point<int> &p) {
    std::cout << "(" << p.m_x << ", " << p.m_y << ")" << std::endl;
}
```

### 5.2 函数模板作为友元

```cpp
#include <iostream>

// 前置声明
template <typename T> class Storage;
template <typename T> void Display(const Storage<T> &s);

template <typename T>
class Storage {
private:
    T m_data;

public:
    Storage(T data) : m_data(data) {}

    // 将特定的模板实例声明为友元
    friend void Display<T>(const Storage<T> &s);
};

template <typename T>
void Display(const Storage<T> &s) {
    std::cout << "存储的值: " << s.m_data << std::endl;
}

int main() {
    Storage<int> st(42);
    Display(st);

    return 0;
}
```

## 六、模板的分离编译

### 6.1 模板的编译模型

与普通函数和类不同，模板的**声明和定义通常不能分离到 .h 和 .cpp 文件中**。这是因为模板的实例化发生在编译期，编译器需要在实例化点看到模板的完整定义。

### 6.2 常见组织方式

**方式一：将定义放在头文件中（推荐）**

```cpp
// 文件: mypair.h
#ifndef MYPAIR_H
#define MYPAIR_H

template <typename T1, typename T2>
class MyPair {
private:
    T1 m_first;
    T2 m_second;

public:
    MyPair(T1 first, T2 second);
    void Display() const;
};

// 成员函数定义也放在头文件中
template <typename T1, typename T2>
MyPair<T1, T2>::MyPair(T1 first, T2 second)
    : m_first(first), m_second(second) {}

template <typename T1, typename T2>
void MyPair<T1, T2>::Display() const {
    std::cout << m_first << " : " << m_second << std::endl;
}

#endif
```

**方式二：使用 .hpp 文件**

许多 C++ 程序员将模板代码放在 `.hpp`（header plus plus）文件中，表示这个文件既包含声明也包含定义，使用时直接 `#include` 该文件即可。

### 6.3 显式实例化（解决分离编译）

如果一定要将模板定义放在 .cpp 文件中，可以使用显式实例化：

```cpp
// 文件: myclass.h
template <typename T>
class MyClass {
public:
    void Show(T value);
};

// 文件: myclass.cpp
#include "myclass.h"
#include <iostream>

template <typename T>
void MyClass<T>::Show(T value) {
    std::cout << "值: " << value << std::endl;
}

// 显式实例化——告诉编译器为这些类型生成代码
template class MyClass<int>;
template class MyClass<double>;
```

但这种方式的缺点是：使用者只能使用已经显式实例化了的类型，失去了模板的通用性。因此，**第一种方式（全部放在头文件中）是实际项目中最常见的选择。**

## 七、综合案例：用模板实现通用栈

下面通过一个综合案例，将函数模板和类模板的知识融会贯通。

```cpp
#include <iostream>
#include <string>

// 基于模板的通用栈
template <typename T, int Capacity = 100>
class Stack {
private:
    T m_data[Capacity];
    int m_top;  // 栈顶索引，-1 表示空栈

public:
    Stack() : m_top(-1) {}

    // 入栈
    bool Push(const T &value) {
        if (m_top >= Capacity - 1) {
            return false;  // 栈满
        }
        m_data[++m_top] = value;
        return true;
    }

    // 出栈
    bool Pop(T &value) {
        if (IsEmpty()) {
            return false;  // 栈空
        }
        value = m_data[m_top--];
        return true;
    }

    // 查看栈顶元素（不弹出）
    bool Peek(T &value) const {
        if (IsEmpty()) {
            return false;
        }
        value = m_data[m_top];
        return true;
    }

    bool IsEmpty() const {
        return m_top == -1;
    }

    bool IsFull() const {
        return m_top >= Capacity - 1;
    }

    int GetSize() const {
        return m_top + 1;
    }
};

// 函数模板：打印栈的内容（从栈底到栈顶）
template <typename T, int N>
void PrintStack(const Stack<T, N> &st) {
    Stack<T, N> temp = st;
    T values[st.GetSize()];
    int count = 0;

    // 将栈内容弹出到数组
    T value;
    while (temp.Pop(value)) {
        values[count++] = value;
    }

    // 反向输出（从栈底到栈顶）
    std::cout << "[底部] ";
    for (int i = count - 1; i >= 0; i--) {
        std::cout << values[i] << " ";
    }
    std::cout << "[顶部]" << std::endl;
}

int main() {
    // 存储 int 的栈
    Stack<int, 10> intStack;

    intStack.Push(10);
    intStack.Push(20);
    intStack.Push(30);

    std::cout << "intStack 大小: " << intStack.GetSize() << std::endl;
    PrintStack(intStack);

    int topVal;
    intStack.Peek(topVal);
    std::cout << "栈顶元素: " << topVal << std::endl;

    intStack.Pop(topVal);
    std::cout << "弹出: " << topVal << std::endl;
    PrintStack(intStack);

    // 存储 string 的栈
    Stack<std::string> strStack;  // 使用默认容量 100

    strStack.Push("C++");
    strStack.Push("模板");
    strStack.Push("泛型编程");

    PrintStack(strStack);

    return 0;
}
```

这个综合案例体现了：
1. **类模板**：`Stack<T, Capacity>` 可以存储任意类型的数据
2. **非类型模板参数**：`Capacity` 作为编译期常量指定栈容量
3. **函数模板**：`PrintStack` 使用函数模板打印不同数据类型的栈内容
4. **代码复用**：同一套栈逻辑，既能处理 int，也能处理 string 等自定义类型

## 八、总结

### 8.1 核心要点回顾

| 知识点 | 关键要点 |
|-------|---------|
| 函数模板 | 参数化函数的数据类型，支持隐式和显式实例化 |
| 类模板 | 参数化类的成员数据类型，必须显式指定类型 |
| 模板特化 | 为特定类型提供特殊的实现，类模板支持偏特化 |
| 非类型参数 | 将常量值作为模板参数，必须是编译期常量 |
| 模板的编译 | 定义通常需要放在头文件中，以便编译器实例化 |

### 8.2 模板的优势

1. **代码复用**：一份模板代码可以服务无限多种数据类型
2. **类型安全**：模板是编译期机制，类型错误在编译时就能被发现
3. **零开销抽象**：使用模板不会带来运行时的性能损失，编译器为每种类型生成专用的代码
4. **灵活性**：通过特化和偏特化，可以在保持通用性的同时处理特殊情况

### 8.3 学习模板的意义

模板是现代 C++ 标准库（STL）的基石。理解模板的工作原理，是驾驭 STL 容器（vector、list、map 等）、算法（sort、find、for_each 等）和迭代器的基础。虽然日常开发中我们更多是使用 STL 中现成的模板组件，但深入理解模板机制，能帮助我们写出更加通用、可复用、高效的 C++ 代码。

从下一篇文章开始，我们将正式进入 STL 的世界，看看 C++ 标准库是如何运用泛型编程思想构建出一套完整的数据结构与算法体系的。
