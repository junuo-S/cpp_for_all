# C++文件操作

## 一、文件操作概述

程序运行时产生的数据默认存在于内存中，一旦程序结束，所有数据都会被释放。为了让数据能够持久保存，我们需要将数据写入到**文件**中，这就是所谓的**数据持久化**。

C++ 通过标准库中的**文件流（fstream）** 机制提供了对文件的读写能力。与传统的 C 语言 `fopen`/`fclose` 相比，C++ 的文件流提供了更面向对象的接口，使用起来更加安全和方便。

### 1.1 文件的两种类型

C++ 将文件分为两大类：

| 文件类型 | 存储方式 | 特点 |
|--------|---------|------|
| 文本文件（Text File） | 以 ASCII 码的形式存储 | 可以用文本编辑器直接查看和修改 |
| 二进制文件（Binary File） | 以原始的二进制形式存储 | 用户一般无法直接阅读，存储效率更高 |

### 1.2 文件操作的三类流对象

C++ 在 `<fstream>` 头文件中提供了三个核心类用于文件操作：

| 类名 | 用途 |
|------|------|
| `ofstream` | 写文件操作（输出流） |
| `ifstream` | 读文件操作（输入流） |
| `fstream` | 读写文件操作（输入输出流） |

> **注意：** 使用任何文件操作前，都必须包含头文件 `#include <fstream>`。

## 二、文本文件的写入

### 2.1 写入的基本流程

文本文件写入有固定的五个步骤：

1. **包含头文件**：`#include <fstream>`
2. **创建流对象**：`ofstream ofs;`
3. **打开文件**：`ofs.open("文件路径", 打开方式);`
4. **写数据**：`ofs << "要写入的内容";`
5. **关闭文件**：`ofs.close();`

### 2.2 文件的打开方式

`open()` 函数的第二个参数是打开方式，它决定了如何操作文件：

| 打开方式 | 含义 |
|---------|------|
| `ios::in` | 为读文件而打开文件 |
| `ios::out` | 为写文件而打开文件 |
| `ios::ate` | 初始位置定位到文件末尾 |
| `ios::app` | 追加方式写入（在文件末尾添加内容） |
| `ios::trunc` | 如果文件存在，先删除后重新创建 |
| `ios::binary` | 以二进制方式操作 |

多个打开方式可以用 `|` 操作符组合使用。例如 `ios::out | ios::binary` 表示以二进制方式写入。

### 2.3 写入示例

**示例：将个人信息写入文本文件**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    // 1. 创建输出流对象
    ofstream ofs;
    
    // 2. 打开文件（如果文件不存在则创建）
    //    ios::out 会清空原有内容重新写入
    ofs.open("student.txt", ios::out);
    
    // 3. 写入数据
    ofs << "姓名：张三" << endl;
    ofs << "年龄：20" << endl;
    ofs << "学号：2023001" << endl;
    ofs << "专业：计算机科学与技术" << endl;
    
    // 4. 关闭文件
    ofs.close();
    
    cout << "文件写入成功！" << endl;
    
    return 0;
}
```

运行后，会在程序所在目录生成一个 `student.txt` 文件，内容如下：

```
姓名：张三
年龄：20
学号：2023001
专业：计算机科学与技术
```

### 2.4 追加写入

如果不想覆盖原有内容，而是在文件末尾追加数据，可以使用 `ios::app` 模式：

```cpp
#include <fstream>
using namespace std;

int main() {
    ofstream ofs;
    
    // 追加方式打开，原有内容不会被清空
    ofs.open("student.txt", ios::app);
    
    ofs << "备注：该生成绩优秀" << endl;
    
    ofs.close();
    
    return 0;
}
```

运行后，`student.txt` 末尾会增加一行"备注：该生成绩优秀"。

### 2.5 直接在构造函数中打开文件

`ofstream` 的构造函数可以直接接收文件路径和打开方式，省略 `open()` 调用：

```cpp
#include <fstream>
using namespace std;

int main() {
    // 直接在对象构造时打开文件
    ofstream ofs("log.txt", ios::out);
    
    ofs << "程序启动日志" << endl;
    ofs << "时间：2024-01-15 10:30:00" << endl;
    
    ofs.close();
    
    return 0;
}
```

## 三、文本文件的读取

### 3.1 读取的基本流程

文本文件读取同样遵循固定的步骤：

1. **包含头文件**：`#include <fstream>`
2. **创建流对象**：`ifstream ifs;`
3. **打开文件并判断是否成功**：`ifs.open("文件路径", 打开方式);`
4. **读数据**：有多种读取方式，可灵活选择
5. **关闭文件**：`ifs.close();`

### 3.2 四种读取方式

C++ 提供了多种读取文本文件的方式，下面逐一演示。

**方式一：逐词语读取（以空格和换行分隔）**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    ifstream ifs;
    ifs.open("student.txt", ios::in);
    
    // 判断文件是否成功打开
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    char buf[1024] = {0};
    // >> 运算符以空白字符（空格、制表符、换行）作为分隔符
    while (ifs >> buf) {
        cout << buf << endl;
    }
    
    ifs.close();
    return 0;
}
```

**方式二：逐行读取（C 风格）**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    ifstream ifs("student.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    char buf[1024] = {0};
    // getline() 每次读取一行
    while (ifs.getline(buf, sizeof(buf))) {
        cout << buf << endl;
    }
    
    ifs.close();
    return 0;
}
```

**方式三：逐行读取（C++ 风格，使用 string）**

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ifstream ifs("student.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    string buf;
    // 全局函数 getline()，需要包含 <string>
    while (getline(ifs, buf)) {
        cout << buf << endl;
    }
    
    ifs.close();
    return 0;
}
```

**方式四：逐字符读取**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    ifstream ifs("student.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    char c;
    // get() 每次读取一个字符，EOF 表示文件结束
    while ((c = ifs.get()) != EOF) {
        cout << c;  // 字符本身就包含换行，所以不用加 endl
    }
    
    ifs.close();
    return 0;
}
```

### 3.3 四种方式的对比

| 读取方式 | 适用场景 | 优点 | 缺点 |
|--------|---------|------|------|
| `>>` 逐词读取 | 处理以空白分隔的数据（如配置文件） | 简单快捷，自动跳过空白 | 无法读取包含空格的字段 |
| `getline(buf, size)` | 逐行处理文本 | 读取整行，含空格 | 需预分配缓冲区，有最大长度限制 |
| `getline(ifs, str)` | 逐行处理文本 | 自动管理内存，无长度限制 | 需要包含 `<string>` |
| `get()` 逐字符 | 精确控制，字符级处理 | 最灵活，不会跳过任何字符 | 效率较低 |

## 四、文本文件的实际应用案例

### 4.1 简单的配置文件解析

创建一个简单的配置文件 `config.txt`：

```
server=127.0.0.1
port=8080
timeout=30
```

编写程序读取并解析该文件：

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ifstream ifs("config.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "配置文件打开失败！" << endl;
        return 1;
    }
    
    string line;
    while (getline(ifs, line)) {
        // 查找 '=' 分隔符的位置
        size_t pos = line.find('=');
        if (pos != string::npos) {
            string key = line.substr(0, pos);
            string value = line.substr(pos + 1);
            cout << "键：" << key << "，值：" << value << endl;
        }
    }
    
    ifs.close();
    return 0;
}
```

### 4.2 通讯录数据读写

**写入通讯录：**

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Contact {
    char name[32];
    char phone[20];
    int age;
};

int main() {
    Contact contacts[3] = {
        {"张三", "13800138001", 25},
        {"李四", "13900139002", 30},
        {"王五", "13700137003", 28}
    };
    
    ofstream ofs("contacts.txt", ios::out);
    
    for (int i = 0; i < 3; i++) {
        ofs << contacts[i].name << ","
            << contacts[i].phone << ","
            << contacts[i].age << endl;
    }
    
    ofs.close();
    cout << "通讯录写入完成" << endl;
    
    return 0;
}
```

**读取通讯录：**

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ifstream ifs("contacts.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    string line;
    cout << "通讯录内容：" << endl;
    cout << "姓名\t电话\t\t年龄" << endl;
    cout << "----------------------------" << endl;
    
    while (getline(ifs, line)) {
        // 解析逗号分隔的字段
        size_t pos1 = line.find(',');
        size_t pos2 = line.rfind(',');
        
        string name = line.substr(0, pos1);
        string phone = line.substr(pos1 + 1, pos2 - pos1 - 1);
        string age = line.substr(pos2 + 1);
        
        cout << name << "\t" << phone << "\t" << age << endl;
    }
    
    ifs.close();
    return 0;
}
```

## 五、二进制文件的写入

### 5.1 二进制写入的特点

二进制文件以内存中的原始形式存储数据，而不是转换为可读的文本。它的主要特点包括：

- **存储效率高**：整数以 4 字节直接存储，而不是转为字符串
- **读写速度快**：不需要进行文本解析转换
- **不可直接阅读**：用文本编辑器打开是乱码
- **适合存储结构化数据**：如结构体、对象

### 5.2 write() 函数

二进制写入的核心函数是 `write()`，其函数原型如下：

```cpp
ostream& write(const char* buffer, int len);
```

- `buffer`：指向内存中待写入数据的首地址
- `len`：要写入的字节数

### 5.3 基本写入示例

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    char name[32];
    int age;
    double score;
};

int main() {
    Student stu = {"张三", 20, 95.5};
    
    // 以二进制方式打开文件
    ofstream ofs("student.dat", ios::out | ios::binary);
    
    // 将结构体数据以二进制形式写入文件
    ofs.write((const char*)&stu, sizeof(stu));
    
    ofs.close();
    cout << "二进制文件写入完成" << endl;
    
    return 0;
}
```

### 5.4 写入结构体数组

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    char name[32];
    int age;
    double score;
};

int main() {
    Student students[3] = {
        {"张三", 20, 95.5},
        {"李四", 22, 87.0},
        {"王五", 21, 91.5}
    };
    
    ofstream ofs("students.dat", ios::out | ios::binary);
    
    // 一次性写入整个数组
    ofs.write((const char*)students, sizeof(students));
    
    ofs.close();
    cout << "批量写入 " << 3 << " 条记录" << endl;
    
    return 0;
}
```

### 5.5 多个对象连续写入

实际开发中，更常见的是逐个写入对象，以便灵活控制：

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    char name[32];
    int age;
    double score;
};

int main() {
    Student s1 = {"张三", 20, 95.5};
    Student s2 = {"李四", 22, 87.0};
    
    ofstream ofs("students2.dat", ios::out | ios::binary);
    
    // 逐个写入
    ofs.write((const char*)&s1, sizeof(s1));
    ofs.write((const char*)&s2, sizeof(s2));
    
    ofs.close();
    cout << "逐个写入完成" << endl;
    
    return 0;
}
```

## 六、二进制文件的读取

### 6.1 read() 函数

二进制读取的核心函数是 `read()`，其函数原型如下：

```cpp
istream& read(char* buffer, int len);
```

- `buffer`：指向内存中接收数据的缓冲区首地址
- `len`：要读取的字节数

### 6.2 读取单个对象

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    char name[32];
    int age;
    double score;
};

int main() {
    Student stu;
    
    ifstream ifs("student.dat", ios::in | ios::binary);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    ifs.read((char*)&stu, sizeof(stu));
    
    cout << "姓名：" << stu.name << endl;
    cout << "年龄：" << stu.age << endl;
    cout << "成绩：" << stu.score << endl;
    
    ifs.close();
    return 0;
}
```

### 6.3 循环读取所有对象

当文件中存储了多个结构体对象时，可以通过循环逐条读取：

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    char name[32];
    int age;
    double score;
};

int main() {
    Student stu;
    
    ifstream ifs("students.dat", ios::in | ios::binary);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return 1;
    }
    
    cout << "读取到的学生信息：" << endl;
    cout << "姓名\t年龄\t成绩" << endl;
    cout << "------------------------" << endl;
    
    // 循环读取，read() 返回 false 表示读取失败（到达文件末尾）
    while (ifs.read((char*)&stu, sizeof(stu))) {
        cout << stu.name << "\t" << stu.age << "\t" << stu.score << endl;
    }
    
    ifs.close();
    return 0;
}
```

> **关键点：** 二进制读写必须保证结构体/对象的内存布局完全一致。读取时用 `sizeof()` 计算的字节数必须等于写入时的字节数，否则会导致数据错位。

## 七、文件状态检查

在进行文件操作时，检查文件状态是非常重要的编程习惯。C++ 的流对象提供了多个成员函数用于状态检查：

### 7.1 常用状态函数

| 函数 | 含义 |
|------|------|
| `is_open()` | 文件是否成功打开 |
| `good()` | 文件流状态是否正常 |
| `fail()` | 最后一次操作是否失败 |
| `eof()` | 是否已到达文件末尾 |
| `bad()` | 是否发生了不可恢复的错误 |

### 7.2 综合状态检查示例

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main() {
    ifstream ifs;
    
    ifs.open("nonexistent.txt", ios::in);
    
    // 1. 检查文件是否打开
    if (!ifs.is_open()) {
        cout << "文件不存在或无法打开！" << endl;
        return 1;
    }
    
    // 2. 读取所有内容
    char buf[256];
    while (ifs.getline(buf, sizeof(buf))) {
        cout << buf << endl;
    }
    
    // 3. 检查读取结束的原因
    if (ifs.eof()) {
        cout << "文件读取完毕（正常结束）" << endl;
    } else if (ifs.fail()) {
        cout << "读取过程中出现格式错误" << endl;
    } else if (ifs.bad()) {
        cout << "发生了不可恢复的错误" << endl;
    }
    
    ifs.close();
    return 0;
}
```

## 八、综合案例：学生成绩管理系统

下面通过一个完整的案例，综合展示文本文件和二进制文件的操作。

### 8.1 使用文本文件保存成绩单

```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

struct Score {
    char name[32];
    int chinese;
    int math;
    int english;
};

// 写入成绩
void writeScores() {
    Score scores[3] = {
        {"张三", 85, 92, 78},
        {"李四", 90, 88, 95},
        {"王五", 76, 83, 89}
    };
    
    ofstream ofs("scores.txt", ios::out);
    
    ofs << "姓名 语文 数学 英语" << endl;
    for (int i = 0; i < 3; i++) {
        ofs << scores[i].name << " "
            << scores[i].chinese << " "
            << scores[i].math << " "
            << scores[i].english << endl;
    }
    
    ofs.close();
    cout << "成绩单已保存到 scores.txt" << endl;
}

// 读取并计算总分
void readScores() {
    ifstream ifs("scores.txt", ios::in);
    if (!ifs.is_open()) {
        cout << "文件打开失败！" << endl;
        return;
    }
    
    // 跳过表头
    string header;
    getline(ifs, header);
    
    string name;
    int chinese, math, english;
    
    cout << "成绩统计结果：" << endl;
    cout << "姓名\t总分\t平均分" << endl;
    cout << "------------------------" << endl;
    
    while (ifs >> name >> chinese >> math >> english) {
        int total = chinese + math + english;
        double avg = total / 3.0;
        cout << name << "\t" << total << "\t" << avg << endl;
    }
    
    ifs.close();
}

int main() {
    writeScores();
    readScores();
    
    return 0;
}
```

### 8.2 使用二进制文件保存学生信息

```cpp
#include <fstream>
#include <iostream>
using namespace std;

struct Student {
    int id;
    char name[32];
    int age;
};

// 添加学生
void addStudent(const char* filename, const Student& stu) {
    // ios::app 以追加方式写入，不影响已有数据
    ofstream ofs(filename, ios::out | ios::binary | ios::app);
    
    ofs.write((const char*)&stu, sizeof(stu));
    
    ofs.close();
}

// 查询所有学生
void listStudents(const char* filename) {
    ifstream ifs(filename, ios::in | ios::binary);
    if (!ifs.is_open()) {
        cout << "文件不存在或打开失败！" << endl;
        return;
    }
    
    Student stu;
    cout << "学号\t姓名\t年龄" << endl;
    cout << "------------------------" << endl;
    
    while (ifs.read((char*)&stu, sizeof(stu))) {
        cout << stu.id << "\t" << stu.name << "\t" << stu.age << endl;
    }
    
    ifs.close();
}

int main() {
    const char* filename = "students.dat";
    
    // 先写入两条记录
    Student s1 = {1001, "张三", 20};
    Student s2 = {1002, "李四", 22};
    Student s3 = {1003, "王五", 21};
    
    addStudent(filename, s1);
    addStudent(filename, s2);
    addStudent(filename, s3);
    
    cout << "当前学生列表：" << endl;
    listStudents(filename);
    
    return 0;
}
```

## 九、常见问题与注意事项

### 9.1 文件路径问题

C++ 中文件路径推荐使用**相对路径**，这样程序在不同机器上运行时更加灵活。但需要注意：相对路径是相对于**程序的工作目录**（Working Directory），而不是可执行文件所在的目录。

在 Windows 中使用绝对路径时，反斜杠需要转义：

```cpp
// 错误的写法：\t 会被解释为制表符
ofs.open("C:\test\data.txt", ios::out);

// 正确的写法
ofs.open("C:\\test\\data.txt", ios::out);
// 或者使用正斜杠（Windows 也支持）
ofs.open("C:/test/data.txt", ios::out);
```

### 9.2 二进制文件与跨平台问题

二进制文件在不同平台（Windows、Linux、macOS）之间不一定兼容，原因包括：

- **字节序（Endianness）不同**：x86 使用小端序，而某些嵌入式平台使用大端序
- **结构体对齐（Struct Padding）不同**：不同编译器或不同编译选项会导致结构体内存布局不同
- **基本类型大小不同**：例如 `long` 在 Windows 上是 4 字节，在 Linux 64 位上是 8 字节

如果需要跨平台读写二进制文件，建议使用 `char[]` 定长数组保存字符串，并明确记录每个字段的字节数。

### 9.3 忘记关闭文件

虽然流对象在销毁时会自动调用 `close()`，但显式关闭文件是一个好习惯：

- 确保数据完全写入磁盘（缓冲区刷新）
- 释放文件句柄，让其他程序可以访问该文件
- 代码意图更加清晰

### 9.4 文件存在性检查

在读取文件之前，一定要检查文件是否成功打开。直接操作未成功打开的文件流会导致未定义行为（程序崩溃或读取到垃圾数据）。

## 总结

- C++ 通过 `<fstream>` 头文件中的 `ofstream`、`ifstream`、`fstream` 三个类实现文件读写
- **文本文件**以 ASCII 码存储，可读性强，适合配置文件和日志
- **二进制文件**以原始格式存储，效率高，适合结构化数据
- 文件打开方式可以组合使用，如 `ios::out | ios::binary`
- 文本文件读取有四种方式：`>>` 逐词、`getline(buf, size)`、`getline(ifs, str)`、`get()` 逐字符
- 二进制文件读写分别使用 `write()` 和 `read()` 函数
- 操作完成后务必调用 `close()` 关闭文件
- 养成良好的习惯：每次打开文件后都检查 `is_open()` 的返回值
