# 11 排序算法详解

## 一、排序算法概述

### 1.1 为什么要手写排序？

标准库的 `std::sort` 已经足够高效，为什么还要学习手写排序？

- **面试与算法竞赛**：排序是考察分治、递归、数据结构（堆）等核心思想的经典载体。
- **理解底层原理**：`std::sort` 内部是 IntroSort（快排 + 堆排 + 插入排序的混合），只有理解各算法才能读懂源码。
- **定制化需求**：某些场景需要稳定排序、外部排序、或针对特殊数据分布的优化，标准库未必直接满足。

### 1.2 分类维度

排序算法可以从多个维度分类：

| 维度 | 分类 | 说明 |
|------|------|------|
| 比较 vs 非比较 | 比较排序 | 通过元素间两两比较确定顺序（本文全部属于此类） |
| | 非比较排序 | 利用数据本身的数值特征（计数排序、基数排序、桶排序） |
| 稳定性 | 稳定 | 相等元素的相对顺序不变 |
| | 不稳定 | 相等元素的相对顺序可能改变 |
| 空间 | 原地（In-place） | 仅需 O(1) 额外空间 |
| | 非原地 | 需要 O(n) 或更多辅助空间 |

### 1.3 复杂度总览

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|---------|---------|---------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |

> **记忆口诀**："快归堆"对应 O(n log n)，"冒选插"对应 O(n²)——三快三慢，好记好用。

## 二、冒泡排序

### 2.1 基本原理

冒泡排序的核心思想极其直观：**相邻元素两两比较，把较大的元素逐步"冒泡"到数组末端**。

每一轮遍历，最大的未排序元素会被交换到正确位置。经过 n-1 轮后，整个数组有序。

### 2.2 图解过程

以 `[5, 3, 8, 1, 2]` 为例：

```
第 1 轮：
[5, 3, 8, 1, 2]  →  比较 5,3 → 交换
[3, 5, 8, 1, 2]  →  比较 5,8 → 不动
[3, 5, 8, 1, 2]  →  比较 8,1 → 交换
[3, 5, 1, 8, 2]  →  比较 8,2 → 交换
[3, 5, 1, 2, 8]  ← 8 就位

第 2 轮：
[3, 5, 1, 2, 8]  →  比较 3,5 → 不动
[3, 5, 1, 2, 8]  →  比较 5,1 → 交换
[3, 1, 5, 2, 8]  →  比较 5,2 → 交换
[3, 1, 2, 5, 8]  ← 5 就位

第 3 轮：
[3, 1, 2, 5, 8]  →  比较 3,1 → 交换
[1, 3, 2, 5, 8]  →  比较 3,2 → 交换
[1, 2, 3, 5, 8]  ← 3 就位

第 4 轮：
[1, 2, 3, 5, 8]  →  比较 1,2 → 不动
[1, 2, 3, 5, 8]  ← 全部有序，排序完成
```

### 2.3 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;  // 优化：本轮是否发生过交换
        for (int j = 0; j < n - 1 - i; ++j) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        // 如果本轮没有交换，说明已经有序，提前退出
        if (!swapped) break;
    }
}

int main() {
    vector<int> arr = {5, 3, 8, 1, 2};
    bubbleSort(arr);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
1 2 3 5 8
```

### 2.4 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 最好 O(n) | 数组已有序时，一轮遍历无交换即退出（依赖 `swapped` 优化） |
| 最坏/平均 O(n²) | 逆序数组，每轮都需完整遍历 |
| 空间 O(1) | 仅用常数变量 |
| 稳定性 | **稳定**——只在 `>` 时交换，相等元素不会改变相对顺序 |

> 冒泡排序虽然效率不高，但它是理解"交换排序"思想的入门基石，也是面试中考察优化意识的高频题目。

## 三、选择排序

### 3.1 基本原理

选择排序的思路同样朴素：**每一轮从未排序部分选出最小元素，放到已排序部分的末尾**。

与冒泡排序的区别在于：冒泡通过多次交换逐步移动元素，而选择排序每轮只做一次交换。

### 3.2 图解过程

以 `[64, 25, 12, 22, 11]` 为例：

```
第 1 轮：在 [64, 25, 12, 22, 11] 中找最小值 11（下标 4），与下标 0 交换
[11, 25, 12, 22, 64]

第 2 轮：在 [25, 12, 22, 64] 中找最小值 12（下标 2），与下标 1 交换
[11, 12, 25, 22, 64]

第 3 轮：在 [25, 22, 64] 中找最小值 22（下标 3），与下标 2 交换
[11, 12, 22, 25, 64]

第 4 轮：在 [25, 64] 中找最小值 25（下标 3），已在正确位置，无需交换
[11, 12, 22, 25, 64]  ← 排序完成
```

### 3.3 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; ++i) {
        int minIdx = i;
        // 在未排序部分 [i+1, n) 中寻找最小值的下标
        for (int j = i + 1; j < n; ++j) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // 将最小值交换到已排序部分的末尾
        if (minIdx != i) {
            swap(arr[i], arr[minIdx]);
        }
    }
}

int main() {
    vector<int> arr = {64, 25, 12, 22, 11};
    selectionSort(arr);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
11 12 22 25 64
```

### 3.4 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 最好/平均/最坏 O(n²) | 无论数据分布如何，都需要完整遍历寻找最小值 |
| 空间 O(1) | 仅用常数变量 |
| 交换次数 | 最多 n-1 次（优于冒泡） |
| 稳定性 | **不稳定** |

**不稳定反例**：

```
数组 [5a, 5b, 2]（5a 在 5b 前面）

第 1 轮：最小值 2（下标 2）与下标 0 的 5a 交换
结果：[2, 5b, 5a]  ← 5a 和 5b 的相对顺序被改变！
```

> 选择排序的交换次数少（最多 n-1 次），在"交换代价远大于比较代价"的场景下有一定优势，但实际工程中很少使用。

## 四、插入排序

### 4.1 基本原理

插入排序模拟了**整理扑克牌**的过程：每次从牌堆中摸一张牌，插入到手中已有牌的合适位置。

算法维护一个"已排序前缀"，每次取下一个元素，在已排序部分中从后向前找到合适位置并插入。

### 4.2 图解过程

以 `[5, 2, 4, 6, 1, 3]` 为例：

```
初始：[5 | 2, 4, 6, 1, 3]    （5 视为已排序）

取 2：2 < 5，5 后移，2 插入位置 0
      [2, 5 | 4, 6, 1, 3]

取 4：4 < 5，5 后移；4 > 2，停止
      [2, 4, 5 | 6, 1, 3]

取 6：6 > 5，无需移动
      [2, 4, 5, 6 | 1, 3]

取 1：1 比所有已排序元素小，全部后移
      [1, 2, 4, 5, 6 | 3]

取 3：3 < 6, 3 < 5, 3 < 4, 3 > 2，插入位置 1
      [1, 2, 3, 4, 5, 6]  ← 排序完成
```

### 4.3 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; ++i) {
        int key = arr[i];  // 当前要插入的元素
        int j = i - 1;

        // 将大于 key 的元素逐个后移
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            --j;
        }
        arr[j + 1] = key;  // 插入到正确位置
    }
}

int main() {
    vector<int> arr = {5, 2, 4, 6, 1, 3};
    insertionSort(arr);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
1 2 3 4 5 6
```

### 4.4 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 最好 O(n) | 数组已有序，每个元素只需比较一次 |
| 最坏/平均 O(n²) | 逆序数组，每个元素需与所有已排序元素比较 |
| 空间 O(1) | 原地排序 |
| 稳定性 | **稳定**——只在 `>` 时后移，相等元素不会被越过 |

### 4.5 适用场景

插入排序虽然平均复杂度为 O(n²)，但在以下场景中表现优异：

- **小规模数据**（n < 50）：常数因子小，比 O(n log n) 算法更快
- **近乎有序的数据**：逆序对极少时接近 O(n)
- **在线排序**：数据逐个到达，每次插入一个元素

> 正因如此，`std::sort`（IntroSort）在递归到小数组时会切换为插入排序，以利用其低常数优势。

## 五、堆排序

### 5.1 前置知识：完全二叉树与堆

**完全二叉树**：除最后一层外每层都是满的，最后一层节点靠左排列。用数组存储时，对于下标 `i` 的节点：

- 父节点：`(i - 1) / 2`
- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`

**最大堆（Max Heap）**：每个节点的值都 **≥** 其孩子的值。堆顶（下标 0）即为最大值。

```
        9
       / \
      7   8
     / \ /
    2  5 3

数组表示：[9, 7, 8, 2, 5, 3]
```

### 5.2 核心操作：siftDown（下沉）

`siftDown` 是堆排序的核心——将某个节点与较大的孩子交换，直到满足堆性质：

```cpp
void siftDown(vector<int>& arr, int i, int heapSize) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && arr[left] > arr[largest])
            largest = left;
        if (right < heapSize && arr[right] > arr[largest])
            largest = right;

        if (largest == i) break;  // 已满足堆性质
        swap(arr[i], arr[largest]);
        i = largest;  // 继续向下检查
    }
}
```

### 5.3 排序过程

堆排序分两步：

1. **建堆**：从最后一个非叶节点开始，逐个 `siftDown`，将无序数组调整为最大堆。
2. **排序**：反复将堆顶（最大值）与末尾交换，缩小堆的范围，对新堆顶执行 `siftDown`。

```
原始数组：[4, 10, 3, 5, 1]

建堆后：  [10, 5, 3, 4, 1]

第 1 步：交换堆顶 10 与末尾 1，siftDown → [5, 4, 3, 1, | 10]
第 2 步：交换堆顶 5 与末尾 1，siftDown → [4, 1, 3, | 5, 10]
第 3 步：交换堆顶 4 与末尾 3，siftDown → [3, 1, | 4, 5, 10]
第 4 步：交换堆顶 3 与末尾 1          → [1, | 3, 4, 5, 10]

最终：[1, 3, 4, 5, 10]
```

### 5.4 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

void siftDown(vector<int>& arr, int i, int heapSize) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && arr[left] > arr[largest])
            largest = left;
        if (right < heapSize && arr[right] > arr[largest])
            largest = right;

        if (largest == i) break;
        swap(arr[i], arr[largest]);
        i = largest;
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();

    // 建堆：从最后一个非叶节点开始下沉
    for (int i = n / 2 - 1; i >= 0; --i) {
        siftDown(arr, i, n);
    }

    // 排序：逐步将堆顶放到末尾
    for (int i = n - 1; i > 0; --i) {
        swap(arr[0], arr[i]);   // 堆顶（最大值）放到末尾
        siftDown(arr, 0, i);    // 对剩余部分重新调整
    }
}

int main() {
    vector<int> arr = {4, 10, 3, 5, 1};
    heapSort(arr);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
1 3 4 5 10
```

### 5.5 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 建堆 O(n) | 虽然看起来是 O(n log n)，但数学证明为 O(n)（大部分节点在底层，下沉距离短） |
| 排序 O(n log n) | n-1 次交换，每次 siftDown 为 O(log n) |
| 总时间 O(n log n) | 最好、平均、最坏均如此——**没有最坏退化问题** |
| 空间 O(1) | 原地排序 |
| 稳定性 | **不稳定**——siftDown 中的交换可能打乱相等元素的顺序 |

> 堆排序的最大优势是**最坏情况仍为 O(n log n) 且原地排序**，这使它成为 `std::sort`（IntroSort）中防止快排退化的兜底策略。

## 六、归并排序

### 6.1 分治思想

归并排序是**分治法（Divide and Conquer）** 的经典应用：

1. **分（Divide）**：将数组从中间拆成两半
2. **治（Conquer）**：递归地对两半分别排序
3. **合（Merge）**：将两个有序子数组合并为一个有序数组

### 6.2 递归拆分与合并

```
[38, 27, 43, 3, 9, 82, 10]
         拆分
[38, 27, 43, 3]    [9, 82, 10]
    拆分                拆分
[38, 27] [43, 3]   [9, 82] [10]
  拆分     拆分       拆分
[38][27] [43][3]   [9][82] [10]
  合并     合并       合并
[27, 38] [3, 43]   [9, 82] [10]
    合并                合并
[3, 27, 38, 43]    [9, 10, 82]
         合并
[3, 9, 10, 27, 38, 43, 82]
```

### 6.3 合并过程详解

合并两个有序数组 `[27, 38]` 和 `[3, 43]`：

```
左 = [27, 38]    右 = [3, 43]    辅助 = []

比较 27 vs 3  → 取 3   → 辅助 = [3]
比较 27 vs 43 → 取 27  → 辅助 = [3, 27]
比较 38 vs 43 → 取 38  → 辅助 = [3, 27, 38]
右侧剩余 43   → 追加   → 辅助 = [3, 27, 38, 43]

将辅助数组拷回原数组对应位置
```

### 6.4 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 合并两个有序子数组 arr[left..mid] 和 arr[mid+1..right]
void merge(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;

    // 双指针归并
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {  // <= 保证稳定性
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }

    // 处理剩余元素
    while (i <= mid)   temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    // 拷回原数组
    for (int p = 0; p < k; ++p) {
        arr[left + p] = temp[p];
    }
}

void mergeSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;  // 递归终止：只有一个元素

    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);       // 排序左半
    mergeSort(arr, mid + 1, right);  // 排序右半
    merge(arr, left, mid, right);    // 合并
}

int main() {
    vector<int> arr = {38, 27, 43, 3, 9, 82, 10};
    mergeSort(arr, 0, arr.size() - 1);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
3 9 10 27 38 43 82
```

### 6.5 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 时间 O(n log n) | 递归深度 log n，每层合并总计 O(n)——最好、平均、最坏均如此 |
| 空间 O(n) | 合并时需要与原数组等长的辅助空间 |
| 稳定性 | **稳定**——合并时用 `<=` 比较，相等元素优先取左侧 |

### 6.6 空间开销讨论

归并排序最大的缺点是 **O(n) 额外空间**。优化方向：

- **小数组切换插入排序**：减少递归层数和临时数组分配次数
- **自底向上迭代版**：避免递归栈开销，按步长 1→2→4→… 逐层合并
- **原地归并**：理论上可行但实现复杂，常数因子大，工程中极少使用

> 当稳定性是硬需求时（如数据库 ORDER BY 多列排序），归并排序是首选。`std::stable_sort` 的实现通常就是归并排序。

## 七、快速排序

### 7.1 分治与枢轴

快速排序同样是分治算法，但思路与归并排序相反：

- **归并**：先拆分，后合并（合并是重点）
- **快排**：先划分（partition），后递归（划分是重点）

核心操作 **partition**：选一个枢轴（pivot），将数组划分为"≤ pivot"和"≥ pivot"两部分，枢轴放到最终位置。

### 7.2 Lomuto 分区方案

Lomuto 方案以最后一个元素为枢轴，用单指针 `i` 追踪"小于区"的右边界：

```cpp
int lomutoPartition(vector<int>& arr, int left, int right) {
    int pivot = arr[right];  // 选最右元素为枢轴
    int i = left;            // i 指向下一个"小于区"的位置

    for (int j = left; j < right; ++j) {
        if (arr[j] < pivot) {
            swap(arr[i], arr[j]);
            ++i;
        }
    }
    swap(arr[i], arr[right]);  // 枢轴归位
    return i;                  // 返回枢轴最终位置
}
```

### 7.3 Hoare 分区方案

Hoare 方案使用双指针从两端向中间逼近，交换逆序对，平均交换次数更少：

```cpp
int hoarePartition(vector<int>& arr, int left, int right) {
    int pivot = arr[left + (right - left) / 2];  // 选中间元素
    int i = left - 1, j = right + 1;

    while (true) {
        do { ++i; } while (arr[i] < pivot);
        do { --j; } while (arr[j] > pivot);
        if (i >= j) return j;
        swap(arr[i], arr[j]);
    }
}
```

> Hoare 方案返回的下标不是枢轴最终位置，递归时应写为 `quickSort(arr, left, p)` 和 `quickSort(arr, p+1, right)`。

### 7.4 代码实现（Lomuto 版）

```cpp
#include <iostream>
#include <vector>
using namespace std;

int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[right];
    int i = left;

    for (int j = left; j < right; ++j) {
        if (arr[j] < pivot) {
            swap(arr[i], arr[j]);
            ++i;
        }
    }
    swap(arr[i], arr[right]);
    return i;
}

void quickSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;

    int p = partition(arr, left, right);
    quickSort(arr, left, p - 1);
    quickSort(arr, p + 1, right);
}

int main() {
    vector<int> arr = {10, 7, 8, 9, 1, 5};
    quickSort(arr, 0, arr.size() - 1);

    for (int v : arr) cout << v << " ";
    cout << endl;
    return 0;
}
```

**输出：**

```
1 5 7 8 9 10
```

### 7.5 最坏情况与优化

**最坏情况**：每次枢轴恰好是最大或最小值，退化为 O(n²)。典型触发场景：

- 对已排序数组使用"取最右"策略
- 所有元素相同

**常见优化手段**：

| 优化 | 做法 | 效果 |
|------|------|------|
| 随机枢轴 | `pivot = arr[left + rand() % (right - left + 1)]` | 避免有序数据退化 |
| 三数取中 | 取 left、mid、right 的中位数作为枢轴 | 对近乎有序的数据效果好 |
| 小数组切插入排序 | 当 `right - left < 16` 时改用插入排序 | 减少递归开销 |
| 三路划分 | 将数组分为 < pivot、== pivot、> pivot 三段 | 处理大量重复元素 |

**三数取中示例**：

```cpp
int medianOfThree(vector<int>& arr, int left, int right) {
    int mid = left + (right - left) / 2;
    if (arr[left] > arr[mid])   swap(arr[left], arr[mid]);
    if (arr[left] > arr[right]) swap(arr[left], arr[right]);
    if (arr[mid] > arr[right])  swap(arr[mid], arr[right]);
    // 此时 arr[mid] 为中位数，将其放到 right-1 位置作为枢轴
    swap(arr[mid], arr[right - 1]);
    return arr[right - 1];
}
```

### 7.6 复杂度与稳定性

| 指标 | 分析 |
|------|------|
| 最好/平均 O(n log n) | 每次划分大致均匀，递归深度 log n |
| 最坏 O(n²) | 每次划分极度不均（1 vs n-1） |
| 空间 O(log n) | 递归栈深度（最坏 O(n)） |
| 稳定性 | **不稳定**——partition 中的远距离交换会打乱相等元素 |

> 快速排序在平均情况下是**最快的内部排序算法**，常数因子小、缓存友好。`std::sort` 的主体就是快排（配合堆排和插入排序形成 IntroSort）。

## 八、总结与对比

### 8.1 六种算法横向对比

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定 | 核心思想 |
|------|---------|---------|------|------|---------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 是 | 相邻交换 |
| 选择排序 | O(n²) | O(n²) | O(1) | 否 | 选最小放前面 |
| 插入排序 | O(n²) | O(n²) | O(1) | 是 | 逐个插入有序区 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 | 建堆 + 取堆顶 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 | 分治 + 合并 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 | 分治 + 划分 |

### 8.2 选型建议

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| 通用排序、追求平均最快 | 快速排序（IntroSort） | 常数小、缓存友好 |
| 需要稳定性 | 归并排序 | 唯一 O(n log n) 且稳定的选择 |
| 内存受限、不允许额外空间 | 堆排序 | 原地 O(n log n) |
| 数据量小（n < 50） | 插入排序 | 常数因子最小 |
| 数据近乎有序 | 插入排序 | 接近 O(n) |
| 需要最坏情况保证 | 堆排序 / IntroSort | 不会退化到 O(n²) |

### 8.3 与 STL 的联系

| STL 函数 | 底层实现 | 特点 |
|----------|---------|------|
| `std::sort` | IntroSort（快排 + 堆排 + 插入排序） | 不稳定，平均最快 |
| `std::stable_sort` | 归并排序 | 稳定，需 O(n) 额外空间 |
| `std::partial_sort` | 堆排序（部分排序） | 只排前 k 个 |
| `std::nth_element` | 快速选择（QuickSelect） | O(n) 平均找到第 k 大 |

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {10, 7, 8, 9, 1, 5};

    // 完全排序（IntroSort）
    sort(arr.begin(), arr.end());
    for (int v : arr) cout << v << " ";
    cout << endl;  // 1 5 7 8 9 10

    // 只排前 3 个最小值
    vector<int> arr2 = {10, 7, 8, 9, 1, 5};
    partial_sort(arr2.begin(), arr2.begin() + 3, arr2.end());
    for (int v : arr2) cout << v << " ";
    cout << endl;  // 1 5 7 ...（后三个顺序不保证）

    // 找第 2 小的元素（O(n) 平均）
    vector<int> arr3 = {10, 7, 8, 9, 1, 5};
    nth_element(arr3.begin(), arr3.begin() + 1, arr3.end());
    cout << "2nd smallest: " << arr3[1] << endl;  // 5

    return 0;
}
```

> 理解手写排序算法，不仅能帮助你在面试中从容应对，更能让你在使用 `std::sort` 时知其所以然——知道它为什么快、什么时候可能不够快、以及何时该换用 `stable_sort`。
