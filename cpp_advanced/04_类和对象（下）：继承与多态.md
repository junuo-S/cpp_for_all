# 类和对象（下）：继承与多态

---

继承（Inheritance）和多态（Polymorphism）是 C++ 面向对象编程中复用与可扩展的基石。继承让我们在已有类的基础上派生出新类，多态则让同一个接口表现出不同的行为——这也是 C++ 面向对象三大特性的最后两项。

---

## 一、继承基础

### 1.1 为什么需要继承

当两个类有大量相似的数据和行为时，如果各自独立编写，就会重复代码。继承可以将共同的部分提取到**基类（父类）**中，让**派生类（子类）**复用。

```cpp
#include <iostream>
#include <string>
using namespace std;

class Animal {
public:
    void eat()   { cout << " 吃东西" << endl; }
    void sleep() { cout << " 睡觉" << endl; }

    void setName(const string& n) { name = n; }
    string getName() const { return name; }

private:
    string name;
};

class Cat : public Animal {
public:
    void meow() { cout << getName() << " 喵喵" << endl; }
};

class Dog : public Animal {
public:
    void bark() { cout << getName() << " 汪汪" << endl; }
};

int main() {
    Cat cat;
    cat.setName("小咪");
    cat.eat();
    cat.sleep();
    cat.meow();

    Dog dog;
    dog.setName("旺财");
    dog.eat();
    dog.sleep();
    dog.bark();

    return 0;
}
```

### 1.2 继承方式

C++ 有三种继承方式，决定了外部和子类对基类成员的访问权限。

| 继承方式 | 基类 public | 基类 protected | 基类 private |
|----------|-------------|----------------|--------------|
| public 继承 | public | protected | 不可见 |
| protected 继承 | protected | protected | 不可见 |
| private 继承 | private | private | 不可见 |

规律：继承方式决定了基类成员在派生类中的最低权限——取"基类权限"和"继承方式"中更严格的那个。

```cpp
class Base {
public:
    int pub = 1;
protected:
    int pro = 2;
private:
    int pri = 3;
};

class PubChild : public Base {
public:
    void show() {
        cout << pub << endl;
        cout << pro << endl;
    }
};
```

> 实际开发中绝大多数情况下使用 `public` 继承。

### 1.3 派生类的构造与析构顺序

构造时：**先构造基类，再构造派生类**。析构时：**先析构派生类，再析构基类**。

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base()  { cout << "Base 构造" << endl; }
    ~Base() { cout << "Base 析构" << endl; }
};

class Derived : public Base {
public:
    Derived()  { cout << "Derived 构造" << endl; }
    ~Derived() { cout << "Derived 析构" << endl; }
};

int main() {
    Derived d;
    return 0;
}
```

```
输出：
Base 构造
Derived 构造
Derived 析构
Base 析构
```

如果基类没有默认构造函数，派生类必须在初始化列表中显式调用基类的有参构造：

```cpp
class Base {
public:
    Base(int x) : value(x) { }
private:
    int value;
};

class Derived : public Base {
public:
    Derived() : Base(0), extra(0) { }
    Derived(int a, int b) : Base(a), extra(b) { }
private:
    int extra;
};
```

## 二、继承中的成员管理

### 2.1 同名成员

当派生类定义了与基类同名的成员时，派生类的成员**隐藏（hide）**基类的成员。需要用作用域运算符 `::` 访问基类的版本。

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    void show() { cout << "Base::show()" << endl; }
    int value = 100;
};

class Derived : public Base {
public:
    void show() { cout << "Derived::show()" << endl; }
    int value = 200;
};

int main() {
    Derived d;
    cout << d.value << endl;       // 200
    cout << d.Base::value << endl; // 100

    d.show();          // Derived::show()
    d.Base::show();    // Base::show()
    return 0;
}
```

> 注意：这是**名字隐藏**，不是重载。即使参数不同，基类同名函数也会被隐藏。

### 2.2 静态成员的继承

静态成员变量和静态成员函数也可以被继承，所有派生类共享同一份。

```cpp
class Base {
public:
    static int count;
    static void showCount() { cout << "Count = " << count << endl; }
};

int Base::count = 0;

class DerivedA : public Base { };
class DerivedB : public Base { };

int main() {
    Base::count = 10;
    cout << DerivedA::count << endl;   // 10
    cout << DerivedB::count << endl;   // 10

    DerivedA::count = 20;
    cout << Base::count << endl;       // 20
    return 0;
}
```

## 三、多继承与菱形继承

### 3.1 多继承

C++ 允许一个类同时继承多个基类。

```cpp
class Teacher {
public:
    void teach() { cout << "教书" << endl; }
};

class Researcher {
public:
    void research() { cout << "做科研" << endl; }
};

class Professor : public Teacher, public Researcher {
public:
    void supervise() { cout << "指导研究生" << endl; }
};

int main() {
    Professor p;
    p.teach();
    p.research();
    p.supervise();
    return 0;
}
```

**多继承的二义性**：如果多个基类有同名的成员，需要作用域分辨。

```cpp
class A { public: void show() { cout << "A" << endl; } };
class B { public: void show() { cout << "B" << endl; } };

class C : public A, public B { };

int main() {
    C c;
    // c.show();     // 二义性！
    c.A::show();     // A
    c.B::show();     // B
    return 0;
}
```

### 3.2 菱形继承

菱形继承（钻石继承）是多继承中一个经典问题。

```
      Animal
     /      \
  Sheep     Camel
     \      /
     Alpaca
```

```cpp
class Animal {
public:
    int age = 0;
};

class Sheep : public Animal { };
class Camel : public Animal { };

class Alpaca : public Sheep, public Camel { };

int main() {
    Alpaca a;
    // a.age = 5;          // 二义性！
    a.Sheep::age = 5;
    a.Camel::age = 3;      // 现在有两份 age

    cout << a.Sheep::age << endl;  // 5
    cout << a.Camel::age << endl;  // 3
    return 0;
}
```

### 3.3 虚继承

虚继承（Virtual Inheritance）解决菱形继承中的数据冗余问题。被虚继承的基类称为**虚基类**，在最终派生类中只保留一份实例。

```cpp
class Animal {
public:
    int age = 0;
};

class Sheep : virtual public Animal { };
class Camel : virtual public Animal { };

class Alpaca : public Sheep, public Camel { };

int main() {
    Alpaca a;
    a.age = 5;                // 现在没有二义性了！

    cout << a.age << endl;    // 5
    return 0;
}
```

**虚基类的构造**：虚基类的构造函数由**最终派生类**负责调用。

```cpp
class Animal {
public:
    Animal(int a) : age(a) { }
    int age;
};

class Sheep : virtual public Animal {
public:
    Sheep() : Animal(0) { }
};

class Camel : virtual public Animal {
public:
    Camel() : Animal(0) { }
};

class Alpaca : public Sheep, public Camel {
public:
    Alpaca() : Animal(5), Sheep(), Camel() { }
};
```

## 四、多态基础

### 4.1 静态多态与动态多态

| 类型 | 绑定时机 | 实现方式 | 典型例子 |
|------|----------|----------|----------|
| 静态多态 | 编译时（早绑定） | 函数重载、模板 | `add(int, int)` 和 `add(double, double)` |
| 动态多态 | 运行时（晚绑定） | 虚函数 + 继承 | 基类指针指向不同的派生类对象 |

### 4.2 虚函数与晚绑定

当基类函数声明为 `virtual` 时，编译器采用**晚绑定**——在运行时根据对象的实际类型决定调用哪个函数。

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    virtual void speak() { cout << "动物叫声" << endl; }
};

class Cat : public Animal {
public:
    void speak() { cout << "喵喵" << endl; }
};

class Dog : public Animal {
public:
    void speak() { cout << "汪汪" << endl; }
};

void makeSound(Animal& a) {
    a.speak();
}

int main() {
    Animal* p1 = new Cat();
    Animal* p2 = new Dog();

    p1->speak();   // 喵喵
    p2->speak();   // 汪汪

    Cat cat;
    Dog dog;
    makeSound(cat);   // 喵喵
    makeSound(dog);   // 汪汪

    delete p1;
    delete p2;
    return 0;
}
```

### 4.3 多态的条件

**多态满足三个条件**：
1. 有**继承**关系
2. 子类**重写**父类的虚函数
3. 父类的**指针或引用**指向子类对象

**多态的工程意义**：将代码从"依赖具体类型"变为"依赖抽象接口"——体现了**开闭原则**。

### 4.4 虚函数表（vtable）

当类中有虚函数时，编译器会为该类生成一个**虚函数表（vtable）**，每个对象多出一个**虚函数指针（vptr）**指向这个表。

```
对象内存布局：
[ vptr ] -> [ vtable: &Base::f, &Base::g, ... ]
[ 其他成员... ]
```

- 每个类（不是每个对象）有一份 vtable。
- 派生类重写虚函数时，vtable 中对应的条目会被替换为派生类的函数地址。
- 虚函数调用比普通函数调用多一次间接寻址，有极小的性能开销。

## 五、纯虚函数与抽象类

### 5.1 纯虚函数

如果基类中的虚函数没有实际意义，可以定义为**纯虚函数**——没有函数体。

```cpp
class Animal {
public:
    virtual void speak() = 0;   // 纯虚函数
};

class Cat : public Animal {
public:
    virtual void speak() { cout << "喵喵" << endl; }
};

int main() {
    // Animal a;   // 错误！抽象类不能实例化
    Animal* p = new Cat();
    p->speak();
    delete p;
    return 0;
}
```

### 5.2 抽象类

包含**至少一个纯虚函数**的类称为**抽象类**。

**特征**：
- 不能实例化对象。
- 子类必须重写所有纯虚函数，否则子类也是抽象类。
- 抽象类可以作为**接口**——定义规范，由派生类实现细节。

```cpp
class Shape {
public:
    virtual double area() const = 0;
    virtual void draw() const = 0;
    virtual ~Shape() { }
};

class Circle : public Shape {
public:
    Circle(double r) : radius(r) { }
    virtual double area() const { return 3.14159 * radius * radius; }
    virtual void draw() const { cout << "画一个圆形" << endl; }
private:
    double radius;
};

class Rectangle : public Shape {
public:
    Rectangle(double w, double h) : width(w), height(h) { }
    virtual double area() const { return width * height; }
    virtual void draw() const { cout << "画一个矩形" << endl; }
private:
    double width, height;
};

void renderShape(const Shape& s) {
    s.draw();
    cout << "面积：" << s.area() << endl;
}

int main() {
    Circle c(5);
    Rectangle r(3, 4);
    renderShape(c);
    renderShape(r);
    return 0;
}
```

## 六、虚析构与纯虚析构

### 6.1 通过父类指针释放子类对象的问题

当使用基类指针管理派生类对象时，如果基类的析构函数不是虚函数，`delete` 时只会调用基类的析构，不会调用派生类的析构——导致资源泄漏。

```cpp
class Base {
public:
    ~Base() { }   // 非虚析构
};

class Derived : public Base {
public:
    Derived() { buffer = new char[1024]; }
    ~Derived() { delete[] buffer; }
private:
    char* buffer;
};

int main() {
    Base* p = new Derived();
    delete p;   // 只调 Base 析构！buffer 泄漏
    return 0;
}
```

### 6.2 虚析构

将基类的析构函数声明为 `virtual`，`delete` 时会先调用派生类析构，再调用基类析构。

```cpp
class Base {
public:
    virtual ~Base() { }
};
```

> **最佳实践**：如果类中有虚函数，析构函数也应该声明为虚析构。

### 6.3 纯虚析构

纯虚析构函数**必须有实现体**，因为基类的析构始终要执行。

```cpp
class AbstractBase {
public:
    virtual void doSomething() = 0;
    virtual ~AbstractBase() = 0;
};

AbstractBase::~AbstractBase() {
    // 纯虚析构必须在类外定义实现
}
```

## 七、综合案例：图形编辑器

综合运用继承、多态、纯虚函数和虚析构，设计一个可扩展的图形编辑器。

```cpp
#include <iostream>
using namespace std;

class Shape {
public:
    Shape(double x, double y) : cx(x), cy(y) { }
    virtual double area() const = 0;
    virtual void draw() const = 0;
    virtual ~Shape() { }
protected:
    double cx, cy;
};

class Circle : public Shape {
public:
    Circle(double x, double y, double r) : Shape(x, y), radius(r) { }
    virtual double area() const { return 3.14159 * radius * radius; }
    virtual void draw() const {
        cout << "Circle: 圆心(" << cx << "," << cy << ") 半径=" << radius
             << " 面积=" << area() << endl;
    }
private:
    double radius;
};

class Rectangle : public Shape {
public:
    Rectangle(double x, double y, double w, double h) : Shape(x, y), width(w), height(h) { }
    virtual double area() const { return width * height; }
    virtual void draw() const {
        cout << "Rectangle: 中心(" << cx << "," << cy << ") 宽=" << width
             << " 高=" << height << " 面积=" << area() << endl;
    }
private:
    double width, height;
};

class Triangle : public Shape {
public:
    Triangle(double x, double y, double b, double h) : Shape(x, y), base(b), height(h) { }
    virtual double area() const { return 0.5 * base * height; }
    virtual void draw() const {
        cout << "Triangle: 中心(" << cx << "," << cy << ") 底=" << base
             << " 高=" << height << " 面积=" << area() << endl;
    }
private:
    double base, height;
};

class Canvas {
public:
    ~Canvas() {
        for (int i = 0; i < count; ++i) delete shapes[i];
    }
    void addShape(Shape* s) {
        if (count < 10) shapes[count++] = s;
    }
    void renderAll() const {
        double total = 0;
        cout << "\n===== 画布内容 =====" << endl;
        for (int i = 0; i < count; ++i) {
            shapes[i]->draw();
            total += shapes[i]->area();
        }
        cout << "共 " << count << " 个图形，总面积：" << total << endl;
    }
private:
    Shape* shapes[10];
    int count = 0;
};

int main() {
    Canvas canvas;
    canvas.addShape(new Circle(0, 0, 5));
    canvas.addShape(new Rectangle(10, 10, 8, 6));
    canvas.addShape(new Triangle(5, 5, 10, 4));
    canvas.addShape(new Circle(-3, -2, 2.5));
    canvas.renderAll();
    return 0;
}
```

## 八、总结

### 继承

| 要点 | 说明 |
|------|------|
| **继承语法** | `class Derived : public Base { };` |
| **继承方式** | public、protected、private 影响派生类中成员的最低权限 |
| **构造析构顺序** | 基类构造 -> 派生类构造 -> 派生类析构 -> 基类析构 |
| **同名隐藏** | 派生类成员隐藏基类同名成员，用 `基类::` 访问 |
| **多继承与虚继承** | 菱形继承导致数据冗余，`virtual` 继承解决 |

### 多态

| 要点 | 说明 |
|------|------|
| **虚函数** | `virtual` 关键字开启晚绑定 |
| **多态条件** | 继承 + 重写 + 父类指针/引用指向子类对象 |
| **纯虚函数** | `virtual void func() = 0`，没有函数体 |
| **抽象类** | 含纯虚函数的类，不能实例化，作为接口 |
| **虚析构** | 基类析构加 `virtual`，确保多态释放子类资源 |

### 从封装到多态的工程思维

C++ 面向对象的三个支柱是层层递进的关系：

1. **封装**把数据和操作组织在一起，控制访问边界。
2. **继承**让类之间复用代码，建立层次关系。
3. **多态**让代码依赖抽象而非具体实现，实现"对扩展开放，对修改封闭"。
