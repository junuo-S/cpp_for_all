# 06 哈希表

## 一、从查找到哈希

### 1.1 查找效率的瓶颈

| 数据结构 | 查找时间 | 限制 |
|---------|---------|------|
| 无序数组 | O(n) | 只能线性扫描 |
| 有序数组 + 二分 | O(log n) | 插入/删除代价高 |
| BST / 平衡树 | O(log n) | 需要维护树结构 |

有没有可能做到 **O(1) 查找**？答案是：**哈希表（Hash Table）**。

### 1.2 哈希的核心思想

通过一个**哈希函数（Hash Function）**，将键（key）直接映射为数组下标：

```
index = hash(key) % table_size
```

理想情况下，每个键映射到不同位置，查找只需一次计算 + 一次数组访问。

---

## 二、哈希函数设计

### 2.1 好的哈希函数的标准

| 标准 | 说明 |
|------|------|
| 确定性 | 相同的 key 必须得到相同的 hash 值 |
| 均匀性 | 输出尽可能均匀分布在 [0, table_size) |
| 高效性 | 计算速度快 |
| 雪崩效应 | 输入微小变化导致输出巨大变化 |

### 2.2 常见哈希方法

**除留余数法**（最常用）：

```cpp
int hash(int key, int tableSize) {
    return key % tableSize;  // tableSize 取素数效果更好
}
```

**字符串哈希**（多项式滚动）：

```cpp
int hashString(const string& s, int tableSize) {
    long long hash = 0;
    int base = 31;  // 常用基数
    for (char c : s) {
        hash = hash * base + c;
    }
    return hash % tableSize;
}
```

> C++ 标准库中 `std::hash<T>` 为内置类型和 `string` 提供了哈希函数，`unordered_map` 默认使用它。

## 三、冲突解决

不同的 key 可能映射到相同下标——这就是**哈希冲突（Collision）**。两种主流解决方案：

### 3.1 链地址法（Separate Chaining）

每个桶（bucket）挂一条链表，冲突元素追加到链表中：

```
bucket[0] → [key1|val] → [key4|val] → null
bucket[1] → [key2|val] → null
bucket[2] → null
bucket[3] → [key3|val] → [key7|val] → [key9|val] → null
```

```cpp
#include <iostream>
#include <list>
#include <vector>
#include <string>
using namespace std;

class HashTable {
private:
    vector<list<pair<string, int>>> buckets;
    int tableSize;

    int hashFunc(const string& key) const {
        long long hash = 0;
        for (char c : key) {
            hash = hash * 31 + c;
        }
        return hash % tableSize;
    }

public:
    HashTable(int size = 16) : tableSize(size), buckets(size) {}

    void put(const string& key, int value) {
        int idx = hashFunc(key);
        // 查找是否已存在
        for (auto& p : buckets[idx]) {
            if (p.first == key) {
                p.second = value;  // 更新
                return;
            }
        }
        buckets[idx].push_back({key, value});  // 插入
    }

    int get(const string& key) const {
        int idx = hashFunc(key);
        for (const auto& p : buckets[idx]) {
            if (p.first == key) return p.second;
        }
        return -1;  // 未找到
    }

    bool remove(const string& key) {
        int idx = hashFunc(key);
        for (auto it = buckets[idx].begin(); it != buckets[idx].end(); ++it) {
            if (it->first == key) {
                buckets[idx].erase(it);
                return true;
            }
        }
        return false;
    }

    void print() const {
        for (int i = 0; i < tableSize; ++i) {
            if (!buckets[i].empty()) {
                cout << "bucket[" << i << "]: ";
                for (const auto& p : buckets[i]) {
                    cout << "(" << p.first << "," << p.second << ") ";
                }
                cout << endl;
            }
        }
    }
};

int main() {
    HashTable ht(8);
    ht.put("apple", 5);
    ht.put("banana", 3);
    ht.put("cherry", 7);
    ht.put("date", 2);
    ht.put("elderberry", 9);

    ht.print();

    cout << "get(banana): " << ht.get("banana") << endl;  // 3
    ht.remove("banana");
    cout << "get(banana) after remove: " << ht.get("banana") << endl;  // -1

    return 0;
}
```

### 3.2 开放寻址法（Open Addressing）

冲突时按某种探测序列寻找下一个空位：

| 探测方式 | 公式 | 特点 |
|---------|------|------|
| 线性探测 | `(h(k) + i) % m` | 简单，但容易产生"聚集" |
| 二次探测 | `(h(k) + i²) % m` | 减少聚集 |
| 双重哈希 | `(h₁(k) + i × h₂(k)) % m` | 分布最均匀 |

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

class OpenAddressHash {
private:
    struct Entry {
        string key;
        int value;
        bool occupied;
        bool deleted;
        Entry() : value(0), occupied(false), deleted(false) {}
    };

    vector<Entry> table;
    int tableSize;
    int count;

    int hashFunc(const string& key) const {
        long long hash = 0;
        for (char c : key) hash = hash * 31 + c;
        return hash % tableSize;
    }

public:
    OpenAddressHash(int size = 16) : tableSize(size), table(size), count(0) {}

    void put(const string& key, int value) {
        int idx = hashFunc(key);
        int firstDeleted = -1;

        for (int i = 0; i < tableSize; ++i) {
            int pos = (idx + i) % tableSize;

            if (!table[pos].occupied && !table[pos].deleted) {
                // 空位
                int insertPos = (firstDeleted != -1) ? firstDeleted : pos;
                table[insertPos].key = key;
                table[insertPos].value = value;
                table[insertPos].occupied = true;
                table[insertPos].deleted = false;
                ++count;
                return;
            }
            if (table[pos].deleted && firstDeleted == -1) {
                firstDeleted = pos;
            }
            if (table[pos].occupied && !table[pos].deleted && table[pos].key == key) {
                table[pos].value = value;  // 更新
                return;
            }
        }
    }

    int get(const string& key) const {
        int idx = hashFunc(key);
        for (int i = 0; i < tableSize; ++i) {
            int pos = (idx + i) % tableSize;
            if (!table[pos].occupied && !table[pos].deleted) return -1;
            if (table[pos].occupied && !table[pos].deleted && table[pos].key == key)
                return table[pos].value;
        }
        return -1;
    }
};

int main() {
    OpenAddressHash ht;
    ht.put("hello", 1);
    ht.put("world", 2);
    ht.put("foo", 3);

    cout << ht.get("hello") << endl;  // 1
    cout << ht.get("world") << endl;  // 2
    cout << ht.get("bar") << endl;    // -1

    return 0;
}
```

### 3.3 两种方案对比

| 维度 | 链地址法 | 开放寻址法 |
|------|---------|-----------|
| 实现复杂度 | 简单 | 较复杂（删除需标记） |
| 缓存性能 | 较差（链表指针追逐） | 较好（连续内存） |
| 负载因子 | 可以 > 1 | 必须 < 1 |
| 内存开销 | 额外指针 | 可能有空位浪费 |
| 典型应用 | `std::unordered_map` | Python dict、Java ThreadLocalMap |

## 四、负载因子与扩容

### 4.1 负载因子

**负载因子（Load Factor）** = 已存元素数 / 桶数量

```
α = n / m
```

- α 越大 → 冲突越多 → 查找越慢
- α 越小 → 空间浪费越多

| 负载因子 | 平均查找长度（链地址法） |
|---------|----------------------|
| 0.5 | ≈ 1.25 次比较 |
| 1.0 | ≈ 1.5 次比较 |
| 2.0 | ≈ 2.0 次比较 |

### 4.2 扩容机制

当负载因子超过阈值（通常 0.75）时：

1. 申请 2 倍大小的新数组
2. 将所有元素**重新哈希**到新数组
3. 释放旧数组

扩容是 O(n)，但均摊到每次插入仍为 O(1)。

> `std::unordered_map` 提供 `load_factor()` 和 `max_load_factor()` 接口，当超过阈值时自动 `rehash`。

## 五、unordered_map 原理与使用

### 5.1 底层结构

`std::unordered_map` 的底层是**链地址法哈希表**：

```
buckets (vector<node*>):
[0] → null
[1] → [key,val,next] → [key,val,next] → null
[2] → [key,val,next] → null
[3] → null
...
```

### 5.2 常用操作与复杂度

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
using namespace std;

int main() {
    unordered_map<string, int> umap;

    // 插入 / 更新
    umap["apple"] = 5;
    umap["banana"] = 3;
    umap.insert({"cherry", 7});
    umap.emplace("date", 2);

    // 查找
    if (umap.count("banana")) {
        cout << "banana: " << umap["banana"] << endl;  // 3
    }

    // 遍历
    cout << "所有键值对:" << endl;
    for (const auto& [key, val] : umap) {
        cout << "  " << key << " = " << val << endl;
    }

    // 删除
    umap.erase("banana");

    // 查看桶信息和负载因子
    cout << "size: " << umap.size() << endl;
    cout << "bucket_count: " << umap.bucket_count() << endl;
    cout << "load_factor: " << umap.load_factor() << endl;

    return 0;
}
```

| 操作 | 平均 | 最坏 |
|------|------|------|
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

> 最坏 O(n) 发生在所有键哈希到同一个桶时（极端冲突），但合理设计哈希函数 + 自动扩容使这种情况在实践中几乎不会出现。

### 5.3 自定义类型的哈希

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
using namespace std;

struct Point {
    int x, y;
    bool operator==(const Point& other) const {
        return x == other.x && y == other.y;
    }
};

// 为 Point 特化 std::hash
namespace std {
    template<>
    struct hash<Point> {
        size_t operator()(const Point& p) const {
            return hash<int>()(p.x) ^ (hash<int>()(p.y) << 16);
        }
    };
}

int main() {
    unordered_map<Point, string> pointNames;
    pointNames[{1, 2}] = "A";
    pointNames[{3, 4}] = "B";

    cout << pointNames[{1, 2}] << endl;  // A

    return 0;
}
```

## 六、哈希表 vs 其他查找结构

| 维度 | 哈希表 | 平衡树（map） | 有序数组 |
|------|--------|-------------|---------|
| 查找 | O(1) 平均 | O(log n) | O(log n) |
| 插入/删除 | O(1) 平均 | O(log n) | O(n) |
| 有序遍历 | 不支持 | 支持 | 支持 |
| 范围查询 | 不支持 | 支持 | 支持 |
| 最坏保证 | 无（O(n)） | 有（O(log n)） | 有 |
| 实现复杂度 | 中（哈希+冲突） | 高（旋转/着色） | 低 |

**选型原则**：

- 只需快速查找、不关心顺序 → `unordered_map` / `unordered_set`
- 需要有序遍历或范围查询 → `map` / `set`
- 数据量小且静态 → 有序数组 + 二分

---

## 七、总结

| 要点 | 内容 |
|------|------|
| 核心思想 | 哈希函数将 key 映射为数组下标，实现 O(1) 平均查找 |
| 冲突解决 | 链地址法（STL 采用）、开放寻址法（线性/二次/双重哈希） |
| 负载因子 | α = n/m，超过阈值（0.75）触发 2 倍扩容 + rehash |
| STL 对应 | `unordered_map`/`unordered_set`（链地址法） |
| 局限性 | 不支持有序遍历、范围查询；最坏 O(n) |
| 工程建议 | 绝大多数键值查找场景首选 `unordered_map`，需要有序时用 `map` |
