# 05 堆与优先队列

## 一、为什么需要堆？

### 1.1 问题引入

假设你需要维护一个动态集合，支持以下操作：

- 插入一个元素
- 取出最大（或最小）元素
- 查看当前最大（或最小）元素

用数组？插入 O(1) 但取最值 O(n)。用 BST？所有操作 O(log n) 但实现复杂。

**堆（Heap）** 提供了一种更简洁的方案：用完全二叉树实现，插入和取最值都是 O(log n)，且实现远比平衡树简单。

### 1.2 堆的定义

| 类型 | 性质 |
|------|------|
| 最大堆（Max Heap） | 每个节点 ≥ 其所有后代 |
| 最小堆（Min Heap） | 每个节点 ≤ 其所有后代 |

堆只关心"谁最大/最小"，**不关心其余元素的顺序**。

### 1.3 堆的数组表示

堆是一棵**完全二叉树**，天然适合用数组存储：

```
        90
       /  \
     80    70
    / \   /
  50  60 30

数组: [90, 80, 70, 50, 60, 30]
```

对于下标 `i`（从 0 开始）：

| 关系 | 公式 |
|------|------|
| 父节点 | `(i - 1) / 2` |
| 左孩子 | `2 * i + 1` |
| 右孩子 | `2 * i + 2` |

## 二、堆的核心操作

### 2.1 上浮（siftUp）

新元素插入到数组末尾后，可能比父节点大（最大堆），需要不断与父节点交换向上移动：

```cpp
void siftUp(vector<int>& heap, int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[i] <= heap[parent]) break;
        swap(heap[i], heap[parent]);
        i = parent;
    }
}
```

### 2.2 下沉（siftDown）

删除堆顶后，将末尾元素放到堆顶，它可能比孩子小，需要不断与较大孩子交换向下移动：

```cpp
void siftDown(vector<int>& heap, int i, int heapSize) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && heap[left] > heap[largest])
            largest = left;
        if (right < heapSize && heap[right] > heap[largest])
            largest = right;

        if (largest == i) break;
        swap(heap[i], heap[largest]);
        i = largest;
    }
}
```

### 2.3 完整最大堆实现

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

class MaxHeap {
private:
    vector<int> data;

    void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (data[i] <= data[parent]) break;
            swap(data[i], data[parent]);
            i = parent;
        }
    }

    void siftDown(int i) {
        int n = data.size();
        while (true) {
            int largest = i;
            int left = 2 * i + 1;
            int right = 2 * i + 2;

            if (left < n && data[left] > data[largest])
                largest = left;
            if (right < n && data[right] > data[largest])
                largest = right;

            if (largest == i) break;
            swap(data[i], data[largest]);
            i = largest;
        }
    }

public:
    // 插入 O(log n)
    void push(int val) {
        data.push_back(val);
        siftUp(data.size() - 1);
    }

    // 取最大值 O(1)
    int top() const {
        if (data.empty()) throw runtime_error("Heap is empty");
        return data[0];
    }

    // 删除最大值 O(log n)
    void pop() {
        if (data.empty()) throw runtime_error("Heap is empty");
        data[0] = data.back();
        data.pop_back();
        if (!data.empty()) siftDown(0);
    }

    bool empty() const { return data.empty(); }
    int size() const { return data.size(); }
};

int main() {
    MaxHeap heap;
    int vals[] = {30, 50, 10, 70, 60, 20};
    for (int v : vals) heap.push(v);

    cout << "依次取出最大值: ";
    while (!heap.empty()) {
        cout << heap.top() << " ";
        heap.pop();
    }
    cout << endl;  // 70 60 50 30 20 10

    return 0;
}
```

### 2.4 建堆（Heapify）

将无序数组一次性调整为堆，有两种方式：

| 方式 | 做法 | 时间复杂度 |
|------|------|-----------|
| 逐个插入 | 对每个元素执行 siftUp | O(n log n) |
| **自底向上** | 从最后一个非叶节点开始，逐个 siftDown | **O(n)** |

```cpp
#include <iostream>
#include <vector>
using namespace std;

void siftDown(vector<int>& arr, int i, int n) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < n && arr[left] > arr[largest]) largest = left;
        if (right < n && arr[right] > arr[largest]) largest = right;

        if (largest == i) break;
        swap(arr[i], arr[largest]);
        i = largest;
    }
}

void buildHeap(vector<int>& arr) {
    int n = arr.size();
    // 从最后一个非叶节点开始
    for (int i = n / 2 - 1; i >= 0; --i) {
        siftDown(arr, i, n);
    }
}

int main() {
    vector<int> arr = {4, 10, 3, 5, 1, 8};
    buildHeap(arr);

    cout << "建堆后: ";
    for (int v : arr) cout << v << " ";
    cout << endl;  // 10 5 8 4 1 3（满足最大堆性质）

    return 0;
}
```

> 自底向上建堆为何是 O(n)？直觉：底层节点多但下沉距离短，顶层节点少但下沉距离长。数学求和后为 O(n)。

## 三、堆排序回顾

堆排序利用最大堆实现升序排列：

1. 建最大堆
2. 反复将堆顶（最大值）与末尾交换，缩小堆范围，siftDown

```cpp
#include <iostream>
#include <vector>
using namespace std;

void siftDown(vector<int>& arr, int i, int heapSize) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < heapSize && arr[left] > arr[largest]) largest = left;
        if (right < heapSize && arr[right] > arr[largest]) largest = right;

        if (largest == i) break;
        swap(arr[i], arr[largest]);
        i = largest;
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();

    // 建堆
    for (int i = n / 2 - 1; i >= 0; --i)
        siftDown(arr, i, n);

    // 排序
    for (int i = n - 1; i > 0; --i) {
        swap(arr[0], arr[i]);
        siftDown(arr, 0, i);
    }
}

int main() {
    vector<int> arr = {12, 11, 13, 5, 6, 7};
    heapSort(arr);

    for (int v : arr) cout << v << " ";
    cout << endl;  // 5 6 7 11 12 13

    return 0;
}
```

| 指标 | 值 |
|------|-----|
| 时间（所有情况） | O(n log n) |
| 空间 | O(1)（原地） |
| 稳定性 | 不稳定 |

## 四、优先队列（priority_queue）

### 4.1 基本使用

`std::priority_queue` 是 STL 对堆的封装，默认是**最大堆**：

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    // 最大堆（默认）
    priority_queue<int> maxPQ;
    maxPQ.push(30);
    maxPQ.push(10);
    maxPQ.push(50);
    maxPQ.push(20);

    cout << "最大堆: ";
    while (!maxPQ.empty()) {
        cout << maxPQ.top() << " ";
        maxPQ.pop();
    }
    cout << endl;  // 50 30 20 10

    // 最小堆：使用 greater 比较器
    priority_queue<int, vector<int>, greater<int>> minPQ;
    minPQ.push(30);
    minPQ.push(10);
    minPQ.push(50);

    cout << "最小堆: ";
    while (!minPQ.empty()) {
        cout << minPQ.top() << " ";
        minPQ.pop();
    }
    cout << endl;  // 10 30 50

    return 0;
}
```

### 4.2 自定义比较器

对结构体排序时，需要自定义比较逻辑：

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

struct Task {
    string name;
    int priority;
};

// 优先级高的排前面（最大堆）
struct TaskCompare {
    bool operator()(const Task& a, const Task& b) {
        return a.priority < b.priority;  // 注意：小于号 = 最大堆
    }
};

int main() {
    priority_queue<Task, vector<Task>, TaskCompare> pq;
    pq.push({"写报告", 2});
    pq.push({"修 Bug", 5});
    pq.push({"开会", 1});
    pq.push({"代码审查", 4});

    cout << "任务处理顺序:" << endl;
    while (!pq.empty()) {
        cout << "  " << pq.top().name
             << " (优先级: " << pq.top().priority << ")" << endl;
        pq.pop();
    }
    // 修 Bug (优先级: 5)
    // 代码审查 (优先级: 4)
    // 写报告 (优先级: 2)
    // 开会 (优先级: 1)

    return 0;
}
```

> 比较器的逻辑容易混淆：`operator()` 返回 `true` 表示 a 的优先级**低于** b（a 排在 b 后面）。用 `<` 得到最大堆，用 `>` 得到最小堆。

### 4.3 经典应用：Top-K 问题

找出数组中第 K 大的元素——维护一个大小为 K 的**最小堆**：

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int findKthLargest(const vector<int>& nums, int k) {
    // 最小堆，大小为 k
    priority_queue<int, vector<int>, greater<int>> minPQ;

    for (int num : nums) {
        minPQ.push(num);
        if ((int)minPQ.size() > k) {
            minPQ.pop();  // 弹出最小的，保留 k 个最大的
        }
    }
    return minPQ.top();  // 堆顶就是第 k 大
}

int main() {
    vector<int> nums = {3, 2, 1, 5, 6, 4};
    cout << findKthLargest(nums, 2) << endl;  // 5
    return 0;
}
```

| 方法 | 时间 | 空间 |
|------|------|------|
| 排序后取第 k 个 | O(n log n) | O(1) |
| 最小堆（大小 k） | O(n log k) | O(k) |
| 快速选择（QuickSelect） | O(n) 平均 | O(1) |

### 4.4 经典应用：合并 K 个有序链表

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

struct Compare {
    bool operator()(ListNode* a, ListNode* b) {
        return a->val > b->val;  // 最小堆
    }
};

ListNode* mergeKLists(vector<ListNode*>& lists) {
    priority_queue<ListNode*, vector<ListNode*>, Compare> pq;

    // 所有链表头入堆
    for (ListNode* head : lists) {
        if (head) pq.push(head);
    }

    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (!pq.empty()) {
        ListNode* node = pq.top();
        pq.pop();

        tail->next = node;
        tail = tail->next;

        if (node->next) pq.push(node->next);
    }

    return dummy.next;
}

int main() {
    // 链表 1: 1 -> 4 -> 5
    // 链表 2: 1 -> 3 -> 4
    // 链表 3: 2 -> 6
    ListNode* l1 = new ListNode(1);
    l1->next = new ListNode(4);
    l1->next->next = new ListNode(5);

    ListNode* l2 = new ListNode(1);
    l2->next = new ListNode(3);
    l2->next->next = new ListNode(4);

    ListNode* l3 = new ListNode(2);
    l3->next = new ListNode(6);

    vector<ListNode*> lists = {l1, l2, l3};
    ListNode* result = mergeKLists(lists);

    while (result) {
        cout << result->val << " ";
        result = result->next;
    }
    cout << endl;  // 1 1 2 3 4 4 5 6

    return 0;
}
```

时间复杂度：O(N log k)，N 为所有节点总数，k 为链表数。

## 五、堆的其他应用

### 5.1 应用场景速查

| 场景 | 堆的作用 |
|------|---------|
| 优先队列 / 任务调度 | 每次取出优先级最高的任务 |
| Top-K 问题 | 维护大小为 K 的堆 |
| 堆排序 | O(n log n) 原地排序 |
| Dijkstra 最短路 | 每次取距离最小的未访问节点 |
| 中位数维护 | 最大堆（左半）+ 最小堆（右半） |
| 合并 K 个有序序列 | 最小堆选取各序列当前最小值 |

### 5.2 对顶堆求中位数

```cpp
#include <iostream>
#include <queue>
using namespace std;

class MedianFinder {
private:
    priority_queue<int> maxHeap;                           // 左半（较小的一半）
    priority_queue<int, vector<int>, greater<int>> minHeap; // 右半（较大的一半）

public:
    void addNum(int num) {
        maxHeap.push(num);
        minHeap.push(maxHeap.top());
        maxHeap.pop();

        // 保证 maxHeap.size() >= minHeap.size()
        if (minHeap.size() > maxHeap.size()) {
            maxHeap.push(minHeap.top());
            minHeap.pop();
        }
    }

    double findMedian() {
        if (maxHeap.size() > minHeap.size())
            return maxHeap.top();
        return (maxHeap.top() + minHeap.top()) / 2.0;
    }
};

int main() {
    MedianFinder mf;
    mf.addNum(1);
    mf.addNum(2);
    cout << mf.findMedian() << endl;  // 1.5
    mf.addNum(3);
    cout << mf.findMedian() << endl;  // 2

    return 0;
}
```

## 六、总结

| 要点 | 内容 |
|------|------|
| 堆的本质 | 用完全二叉树（数组）实现的优先队列 |
| 核心操作 | siftUp（插入）、siftDown（删除/建堆），均 O(log n) |
| 建堆 | 自底向上 siftDown，O(n) |
| 堆排序 | 建堆 + 反复取堆顶，O(n log n)，原地但不稳定 |
| STL 对应 | `std::priority_queue`（默认最大堆，`greater` 变最小堆） |
| 经典应用 | Top-K、合并 K 路、Dijkstra、中位数维护 |

> 堆是"只关心最值"场景的最优解——它不维护全局有序，只保证堆顶是极值，因此比 BST 实现更简单、常数更小。
