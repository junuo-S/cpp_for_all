# 08 图的基本概念与存储

## 一、图是什么？

### 1.1 从树到图

树是层次结构——有根、有方向、无环。但现实世界中很多关系更复杂：

- 社交网络：人与人互相认识（无方向、可能有环）
- 地图导航：城市之间有道路（有距离/权重）
- 网页链接：页面 A 链接到页面 B（有方向）

**图（Graph）** 就是用来建模这种"任意两点之间可能存在关系"的结构。

### 1.2 核心术语

| 术语 | 含义 |
|------|------|
| 顶点（Vertex） | 图中的节点 |
| 边（Edge） | 连接两个顶点的关系 |
| 有向图 / 无向图 | 边是否有方向 |
| 加权图 / 无权图 | 边是否有权重（距离、费用等） |
| 度（Degree） | 与某顶点相连的边数（有向图分入度/出度） |
| 路径（Path） | 从顶点 A 到顶点 B 经过的顶点序列 |
| 环（Cycle） | 起点和终点相同的路径 |
| 连通图 | 任意两点之间都有路径 |
| 稀疏图 / 稠密图 | 边数远少于 / 接近 n² |

### 1.3 图的示例

```
无向图：                    有向加权图：
  0 --- 1                   0 --4--> 1
  |   / |                   |        |
  |  /  |                   2        1
  | /   |                   ↓        ↓
  2 --- 3                   2 --3--> 3
```

## 二、图的存储

### 2.1 邻接矩阵

用二维数组 `adj[i][j]` 表示顶点 i 到 j 是否有边（或边的权重）：

```
无向图（0-1, 0-2, 1-2, 1-3, 2-3）：

    0  1  2  3
0 [ 0, 1, 1, 0 ]
1 [ 1, 0, 1, 1 ]
2 [ 1, 1, 0, 1 ]
3 [ 0, 1, 1, 0 ]
```

```cpp
#include <iostream>
#include <vector>
using namespace std;

class GraphMatrix {
private:
    int n;
    vector<vector<int>> adj;  // 无权图用 0/1，加权图用权重（INF 表示无边）

public:
    GraphMatrix(int vertices) : n(vertices), adj(vertices, vector<int>(vertices, 0)) {}

    void addEdge(int u, int v, int weight = 1) {
        adj[u][v] = weight;
        adj[v][u] = weight;  // 无向图
    }

    bool hasEdge(int u, int v) const {
        return adj[u][v] != 0;
    }

    void print() const {
        cout << "  ";
        for (int i = 0; i < n; ++i) cout << i << " ";
        cout << endl;
        for (int i = 0; i < n; ++i) {
            cout << i << " [";
            for (int j = 0; j < n; ++j) {
                cout << adj[i][j] << (j < n-1 ? "," : "");
            }
            cout << "]" << endl;
        }
    }
};

int main() {
    GraphMatrix g(4);
    g.addEdge(0, 1);
    g.addEdge(0, 2);
    g.addEdge(1, 2);
    g.addEdge(1, 3);
    g.addEdge(2, 3);

    g.print();
    return 0;
}
```

### 2.2 邻接表

每个顶点维护一个链表（或 vector），存储其所有邻居：

```
0: [1, 2]
1: [0, 2, 3]
2: [0, 1, 3]
3: [1, 2]
```

```cpp
#include <iostream>
#include <vector>
#include <list>
using namespace std;

class GraphList {
private:
    int n;
    vector<list<pair<int, int>>> adj;  // pair<邻居, 权重>

public:
    GraphList(int vertices) : n(vertices), adj(vertices) {}

    void addEdge(int u, int v, int weight = 1) {
        adj[u].push_back({v, weight});
        adj[v].push_back({u, weight});  // 无向图
    }

    void print() const {
        for (int i = 0; i < n; ++i) {
            cout << i << ": ";
            for (const auto& [v, w] : adj[i]) {
                cout << v << "(w=" << w << ") ";
            }
            cout << endl;
        }
    }

    int degree(int v) const { return adj[v].size(); }
};

int main() {
    GraphList g(4);
    g.addEdge(0, 1);
    g.addEdge(0, 2);
    g.addEdge(1, 2);
    g.addEdge(1, 3);
    g.addEdge(2, 3);

    g.print();
    cout << "顶点 1 的度: " << g.degree(1) << endl;  // 3

    return 0;
}
```

### 2.3 两种存储方式对比

| 维度 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(V²) | O(V + E) |
| 判断边是否存在 | O(1) | O(degree) |
| 遍历某顶点的所有邻居 | O(V) | O(degree) |
| 适用场景 | 稠密图（E ≈ V²） | 稀疏图（E << V²） |
| 实现复杂度 | 简单 | 稍复杂 |

> 实际工程中，绝大多数图是稀疏图，因此**邻接表**是更常用的存储方式。

## 三、图的遍历

### 3.1 BFS（广度优先搜索）

从起点出发，**逐层向外扩展**，使用队列实现：

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

void bfs(const vector<vector<int>>& adj, int start) {
    int n = adj.size();
    vector<bool> visited(n, false);
    queue<int> q;

    visited[start] = true;
    q.push(start);

    cout << "BFS 遍历: ";
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cout << u << " ";

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
    cout << endl;
}

int main() {
    // 邻接表（无权无向图）
    vector<vector<int>> adj = {
        {1, 2},     // 0 的邻居
        {0, 2, 3},  // 1 的邻居
        {0, 1, 3},  // 2 的邻居
        {1, 2}      // 3 的邻居
    };

    bfs(adj, 0);  // BFS 遍历: 0 1 2 3

    return 0;
}
```

**BFS 的特点**：

- 第一次到达某顶点时经过的路径就是**最短路径**（无权图）
- 时间复杂度 O(V + E)，空间复杂度 O(V)

### 3.2 DFS（深度优先搜索）

沿着一条路径**走到底**再回溯，使用递归（或栈）实现：

```cpp
#include <iostream>
#include <vector>
using namespace std;

void dfs(const vector<vector<int>>& adj, int u, vector<bool>& visited) {
    visited[u] = true;
    cout << u << " ";

    for (int v : adj[u]) {
        if (!visited[v]) {
            dfs(adj, v, visited);
        }
    }
}

int main() {
    vector<vector<int>> adj = {
        {1, 2},
        {0, 2, 3},
        {0, 1, 3},
        {1, 2}
    };

    vector<bool> visited(4, false);
    cout << "DFS 遍历: ";
    dfs(adj, 0, visited);
    cout << endl;  // DFS 遍历: 0 1 2 3

    return 0;
}
```

**DFS 的特点**：

- 适合检测环、拓扑排序、连通分量
- 时间复杂度 O(V + E)，空间复杂度 O(V)（递归栈）

### 3.3 BFS vs DFS

| 维度 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列 | 栈（递归） |
| 遍历顺序 | 逐层扩展 | 一条路走到底 |
| 最短路径（无权图） | 天然保证 | 不保证 |
| 典型应用 | 最短路、层序遍历 | 环检测、拓扑排序、连通分量 |
| 空间 | O(V)（队列） | O(V)（递归栈） |

## 四、连通性判断

### 4.1 连通分量

无向图中，**连通分量**是极大连通子图。遍历所有未访问顶点，每次 BFS/DFS 能到达的所有顶点构成一个连通分量：

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int countComponents(int n, const vector<vector<int>>& adj) {
    vector<bool> visited(n, false);
    int count = 0;

    for (int i = 0; i < n; ++i) {
        if (!visited[i]) {
            ++count;
            // BFS 标记整个连通分量
            queue<int> q;
            q.push(i);
            visited[i] = true;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : adj[u]) {
                    if (!visited[v]) {
                        visited[v] = true;
                        q.push(v);
                    }
                }
            }
        }
    }
    return count;
}

int main() {
    // 6 个顶点，两个连通分量：{0,1,2} 和 {3,4,5}
    vector<vector<int>> adj = {
        {1, 2}, {0, 2}, {0, 1},  // 分量 1
        {4, 5}, {3, 5}, {3, 4}   // 分量 2
    };

    cout << "连通分量数: " << countComponents(6, adj) << endl;  // 2

    return 0;
}
```

### 4.2 有向图的强连通

有向图中，如果 u 能到 v 且 v 也能到 u，则 u、v **强连通**。强连通分量（SCC）的求解算法（Tarjan / Kosaraju）属于进阶内容，此处不展开。

## 五、图的表示选择与 STL 实践

### 5.1 用 STL 快速建图

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
#include <string>
using namespace std;

int main() {
    // 场景：城市之间的航班（加权有向图）
    unordered_map<string, vector<pair<string, int>>> graph;

    graph["北京"].push_back({"上海", 2});
    graph["北京"].push_back({"广州", 3});
    graph["上海"].push_back({"深圳", 2});
    graph["广州"].push_back({"深圳", 1});

    // 查询北京的所有航班
    cout << "从北京出发:" << endl;
    for (const auto& [dest, time] : graph["北京"]) {
        cout << "  → " << dest << " (" << time << "小时)" << endl;
    }

    return 0;
}
```

### 5.2 选型速查

| 场景 | 推荐存储 |
|------|---------|
| 顶点数少（< 1000）且稠密 | 邻接矩阵 |
| 稀疏图（大多数情况） | 邻接表（`vector<vector<int>>`） |
| 顶点是字符串/对象 | `unordered_map<Key, vector<Edge>>` |
| 需要快速判断边存在 | 邻接矩阵 或 `set<pair<int,int>>` |

## 六、总结

| 要点 | 内容 |
|------|------|
| 图的定义 | 顶点集 + 边集，可有向/无向、加权/无权 |
| 邻接矩阵 | O(V²) 空间，O(1) 查边，适合稠密图 |
| 邻接表 | O(V+E) 空间，遍历邻居高效，适合稀疏图 |
| BFS | 队列实现，逐层扩展，无权图最短路 |
| DFS | 递归/栈实现，走到底再回溯，环检测/拓扑排序 |
| 连通性 | BFS/DFS 遍历标记，统计连通分量数 |

> 图的存储和遍历是所有图算法的基础。下一篇将在此基础上讲解 Dijkstra、Bellman-Ford、Floyd、Prim、Kruskal、拓扑排序等经典算法。
