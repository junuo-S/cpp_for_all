# 03 二叉树与二叉搜索树

## 一、树的基本概念

### 1.1 从线性到层次

数组和链表是线性结构——元素一对一排列。但现实世界中大量关系是**层次化**的：

- 文件系统：目录 → 子目录 → 文件
- 组织架构：CEO → 总监 → 经理 → 员工
- HTML DOM：`<html>` → `<body>` → `<div>` → ...

**树（Tree）** 就是用来表达这种层次关系的数据结构。

### 1.2 核心术语

```
        A          ← 根节点（Root）
       / \
      B   C        ← B、C 是 A 的孩子；A 是 B、C 的父节点
     / \   \
    D   E   F      ← D、E 是 B 的孩子；F 是 C 的孩子
```

| 术语 | 含义 |
|------|------|
| 根节点 | 没有父节点的唯一节点 |
| 叶节点 | 没有孩子的节点（D、E、F） |
| 深度 | 从根到该节点的边数（A=0, B=1, D=2） |
| 高度 | 从该节点到最远叶子的边数（A=2, B=1, D=0） |
| 子树 | 以某节点为根的完整子结构 |

## 二、二叉树

### 2.1 二叉树的定义

**二叉树（Binary Tree）**：每个节点最多有**两个**孩子，分别称为左孩子和右孩子。

注意：二叉树不是"度为 2 的树"——度为 2 的树要求每个节点恰好有 2 个孩子，而二叉树允许 0、1、2 个孩子，且**左右有序**。

### 2.2 特殊二叉树

| 类型 | 定义 |
|------|------|
| 满二叉树 | 每层节点数都达到最大（第 k 层有 2^k 个节点） |
| 完全二叉树 | 除最后一层外每层满，最后一层靠左 |
| 二叉搜索树 | 左子树所有节点 < 根 < 右子树所有节点 |
| 平衡二叉树 | 任意节点的左右子树高度差不超过 1（AVL） |

### 2.3 二叉树的性质

| 性质 | 内容 |
|------|------|
| 1 | 第 i 层最多有 2^i 个节点（i 从 0 开始） |
| 2 | 深度为 k 的二叉树最多有 2^(k+1) - 1 个节点 |
| 3 | 对任何二叉树，叶节点数 n₀ = 度为 2 的节点数 n₂ + 1 |
| 4 | 完全二叉树用数组存储时，节点 i 的左孩子为 2i+1，右孩子为 2i+2 |

### 2.4 二叉树的存储

**链式存储**（最常用）：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};
```

**顺序存储**（适合完全二叉树）：

```
数组: [1, 2, 3, 4, 5, 6, 7]

对应树:
        1
       / \
      2   3
     / \ / \
    4  5 6  7
```

## 三、二叉树的遍历

### 3.1 四种遍历方式

```
        1
       / \
      2   3
     / \
    4   5
```

| 遍历方式 | 顺序 | 结果 |
|---------|------|------|
| 前序（Pre-order） | 根 → 左 → 右 | 1 2 4 5 3 |
| 中序（In-order） | 左 → 根 → 右 | 4 2 5 1 3 |
| 后序（Post-order） | 左 → 右 → 根 | 4 5 2 3 1 |
| 层序（Level-order） | 逐层从左到右 | 1 2 3 4 5 |

> 前/中/后序是 DFS（深度优先），层序是 BFS（广度优先）。

### 3.2 递归实现

```cpp
#include <iostream>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";
    preorder(root->left);
    preorder(root->right);
}

void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";
}

int main() {
    //       1
    //      / \
    //     2   3
    //    / \
    //   4   5
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    cout << "前序: "; preorder(root); cout << endl;   // 1 2 4 5 3
    cout << "中序: "; inorder(root); cout << endl;    // 4 2 5 1 3
    cout << "后序: "; postorder(root); cout << endl;  // 4 5 2 3 1

    return 0;
}
```

### 3.3 迭代实现（用栈模拟）

递归的本质是系统栈，我们可以手动用栈来模拟：

```cpp
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

// 前序迭代：根 → 左 → 右
vector<int> preorderIterative(TreeNode* root) {
    vector<int> result;
    if (!root) return result;

    stack<TreeNode*> st;
    st.push(root);

    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();
        result.push_back(node->val);

        // 先压右再压左（栈是 LIFO，保证左先出）
        if (node->right) st.push(node->right);
        if (node->left) st.push(node->left);
    }
    return result;
}

// 中序迭代：左 → 根 → 右
vector<int> inorderIterative(TreeNode* root) {
    vector<int> result;
    stack<TreeNode*> st;
    TreeNode* cur = root;

    while (cur || !st.empty()) {
        // 一路向左走到底
        while (cur) {
            st.push(cur);
            cur = cur->left;
        }
        // 弹出栈顶（最左未访问节点）
        cur = st.top();
        st.pop();
        result.push_back(cur->val);
        // 转向右子树
        cur = cur->right;
    }
    return result;
}

int main() {
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    vector<int> pre = preorderIterative(root);
    cout << "前序(迭代): ";
    for (int v : pre) cout << v << " ";
    cout << endl;  // 1 2 4 5 3

    vector<int> in = inorderIterative(root);
    cout << "中序(迭代): ";
    for (int v : in) cout << v << " ";
    cout << endl;  // 4 2 5 1 3

    return 0;
}
```

### 3.4 层序遍历（BFS）

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int levelSize = q.size();
        vector<int> level;

        for (int i = 0; i < levelSize; ++i) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);

            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}

int main() {
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    vector<vector<int>> levels = levelOrder(root);
    for (auto& level : levels) {
        for (int v : level) cout << v << " ";
        cout << endl;
    }
    // 1
    // 2 3
    // 4 5

    return 0;
}
```

## 四、二叉搜索树（BST）

### 4.1 BST 的定义

二叉搜索树（Binary Search Tree）满足以下性质：

- 左子树所有节点的值 **<** 根节点的值
- 右子树所有节点的值 **>** 根节点的值
- 左右子树也分别是 BST

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13
```

> BST 的中序遍历结果一定是**有序序列**。这是验证 BST 正确性的常用方法。

### 4.2 BST 的查找

```cpp
TreeNode* search(TreeNode* root, int target) {
    if (!root || root->val == target) return root;
    if (target < root->val)
        return search(root->left, target);
    else
        return search(root->right, target);
}
```

平均 O(log n)，最坏 O(n)（退化为链表时）。

### 4.3 BST 的插入

```cpp
TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);

    if (val < root->val)
        root->left = insert(root->left, val);
    else if (val > root->val)
        root->right = insert(root->right, val);
    // 相等则不插入（假设不允许重复）

    return root;
}
```

### 4.4 BST 的删除

删除是 BST 最复杂的操作，分三种情况：

| 情况 | 处理方式 |
|------|---------|
| 叶节点 | 直接删除 |
| 只有一个孩子 | 用孩子替代自己 |
| 有两个孩子 | 找中序后继（右子树最小值）替换，再删除后继 |

```cpp
#include <iostream>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val)
        root->left = insert(root->left, val);
    else if (val > root->val)
        root->right = insert(root->right, val);
    return root;
}

TreeNode* findMin(TreeNode* node) {
    while (node->left) node = node->left;
    return node;
}

TreeNode* deleteNode(TreeNode* root, int key) {
    if (!root) return nullptr;

    if (key < root->val) {
        root->left = deleteNode(root->left, key);
    } else if (key > root->val) {
        root->right = deleteNode(root->right, key);
    } else {
        // 找到要删除的节点
        if (!root->left) {           // 情况 1 & 2：无左孩子
            TreeNode* right = root->right;
            delete root;
            return right;
        } else if (!root->right) {   // 情况 2：无右孩子
            TreeNode* left = root->left;
            delete root;
            return left;
        }
        // 情况 3：有两个孩子
        TreeNode* successor = findMin(root->right);
        root->val = successor->val;
        root->right = deleteNode(root->right, successor->val);
    }
    return root;
}

void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

int main() {
    TreeNode* root = nullptr;
    int vals[] = {8, 3, 10, 1, 6, 14, 4, 7, 13};
    for (int v : vals) {
        root = insert(root, v);  // insert 函数见 4.3
    }

    cout << "删除前: ";
    inorder(root);
    cout << endl;  // 1 3 4 6 7 8 10 13 14

    root = deleteNode(root, 3);  // 删除有两个孩子的节点
    cout << "删除 3 后: ";
    inorder(root);
    cout << endl;  // 1 4 6 7 8 10 13 14

    return 0;
}
```

### 4.5 BST 的复杂度分析

| 操作 | 平均 | 最坏（退化为链表） |
|------|------|-----------------|
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

**退化条件**：按有序序列插入（如 1, 2, 3, 4, 5），BST 变成一条链。

> 解决方案：使用**自平衡二叉搜索树**（AVL 树、红黑树），保证任何情况下高度为 O(log n)。详见下一篇《04 平衡二叉树》。

## 五、BST 的验证与构造

### 5.1 验证一棵树是否为 BST

利用 BST 中序遍历有序的性质：

```cpp
#include <iostream>
#include <climits>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

bool isValidBST(TreeNode* root, long long minVal = LLONG_MIN, long long maxVal = LLONG_MAX) {
    if (!root) return true;
    if (root->val <= minVal || root->val >= maxVal) return false;
    return isValidBST(root->left, minVal, root->val) &&
           isValidBST(root->right, root->val, maxVal);
}

int main() {
    //     5
    //    / \
    //   1   7
    //      / \
    //     6   8
    TreeNode* root = new TreeNode(5);
    root->left = new TreeNode(1);
    root->right = new TreeNode(7);
    root->right->left = new TreeNode(6);
    root->right->right = new TreeNode(8);

    cout << boolalpha << isValidBST(root) << endl;  // true

    return 0;
}
```

### 5.2 由前序+中序构造二叉树

前序确定根，中序划分左右子树：

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

TreeNode* buildTree(const vector<int>& preorder, const vector<int>& inorder,
                    int preL, int preR, int inL, int inR,
                    unordered_map<int, int>& inMap) {
    if (preL > preR) return nullptr;

    int rootVal = preorder[preL];
    TreeNode* root = new TreeNode(rootVal);

    int rootIdx = inMap[rootVal];
    int leftSize = rootIdx - inL;

    root->left = buildTree(preorder, inorder,
                           preL + 1, preL + leftSize,
                           inL, rootIdx - 1, inMap);
    root->right = buildTree(preorder, inorder,
                            preL + leftSize + 1, preR,
                            rootIdx + 1, inR, inMap);
    return root;
}

TreeNode* buildTree(const vector<int>& preorder, const vector<int>& inorder) {
    unordered_map<int, int> inMap;
    for (int i = 0; i < (int)inorder.size(); ++i) {
        inMap[inorder[i]] = i;
    }
    return buildTree(preorder, inorder, 0, preorder.size() - 1,
                     0, inorder.size() - 1, inMap);
}

void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";
}

int main() {
    vector<int> preorder = {3, 9, 20, 15, 7};
    vector<int> inorder = {9, 3, 15, 20, 7};

    TreeNode* root = buildTree(preorder, inorder);

    cout << "后序验证: ";
    postorder(root);
    cout << endl;  // 9 15 7 20 3

    return 0;
}
```

## 六、总结

| 要点 | 内容 |
|------|------|
| 二叉树 | 每个节点最多两个孩子，左右有序 |
| 遍历 | 前/中/后序（DFS）+ 层序（BFS），递归与迭代两种实现 |
| BST 核心性质 | 左 < 根 < 右，中序遍历有序 |
| BST 操作 | 查找/插入 O(log n) 平均，删除需处理三种情况 |
| BST 的缺陷 | 有序插入会退化为链表，需要平衡化 |
| 与 STL 的联系 | `std::set`/`std::map` 底层是红黑树（自平衡 BST） |

> 二叉搜索树是从"线性查找"迈向"对数查找"的关键一步。但普通 BST 无法保证最坏性能，下一篇将介绍 AVL 树和红黑树如何通过自平衡机制解决这一问题。
