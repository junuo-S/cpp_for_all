# 02 栈与队列

## 一、受限的线性表

### 1.1 从线性表到栈和队列

栈和队列本质上都是**操作受限的线性表**：

| 结构 | 限制规则 | 别名 |
|------|---------|------|
| 栈（Stack） | 只允许在一端（栈顶）插入和删除 | 后进先出（LIFO） |
| 队列（Queue） | 一端插入（队尾），另一端删除（队头） | 先进先出（FIFO） |

它们的底层可以用数组或链表实现，区别仅在于**允许操作的位置**。

### 1.2 生活类比

- **栈**：一摞盘子——最后放上去的最先被拿走
- **队列**：银行排队——先来的人先办理业务

## 二、栈

### 2.1 顺序栈（数组实现）

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

class ArrayStack {
private:
    int* data;
    int top;       // 栈顶下标（-1 表示空栈）
    int capacity;

public:
    ArrayStack(int cap = 16) : data(new int[cap]), top(-1), capacity(cap) {}
    ~ArrayStack() { delete[] data; }

    void push(int val) {
        if (top + 1 == capacity) {
            // 扩容
            int* newData = new int[capacity * 2];
            for (int i = 0; i <= top; ++i) newData[i] = data[i];
            delete[] data;
            data = newData;
            capacity *= 2;
        }
        data[++top] = val;
    }

    void pop() {
        if (empty()) throw runtime_error("Stack underflow");
        --top;
    }

    int peek() const {
        if (empty()) throw runtime_error("Stack is empty");
        return data[top];
    }

    bool empty() const { return top == -1; }
    int size() const { return top + 1; }
};

int main() {
    ArrayStack st;
    st.push(10);
    st.push(20);
    st.push(30);

    cout << st.peek() << endl;  // 30
    st.pop();
    cout << st.peek() << endl;  // 20
    cout << "Size: " << st.size() << endl;  // Size: 2

    return 0;
}
```

### 2.2 链式栈（链表实现）

链式栈用单链表实现，**头节点作为栈顶**（插入/删除都在头部，O(1)）：

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

struct StackNode {
    int val;
    StackNode* next;
    StackNode(int v, StackNode* n) : val(v), next(n) {}
};

class LinkedStack {
private:
    StackNode* top;
    int len;

public:
    LinkedStack() : top(nullptr), len(0) {}

    ~LinkedStack() {
        while (top) {
            StackNode* tmp = top;
            top = top->next;
            delete tmp;
        }
    }

    void push(int val) {
        top = new StackNode(val, top);
        ++len;
    }

    void pop() {
        if (!top) throw runtime_error("Stack underflow");
        StackNode* tmp = top;
        top = top->next;
        delete tmp;
        --len;
    }

    int peek() const {
        if (!top) throw runtime_error("Stack is empty");
        return top->val;
    }

    bool empty() const { return top == nullptr; }
    int size() const { return len; }
};

int main() {
    LinkedStack st;
    st.push(1);
    st.push(2);
    st.push(3);

    while (!st.empty()) {
        cout << st.peek() << " ";
        st.pop();
    }
    cout << endl;  // 3 2 1

    return 0;
}
```

### 2.3 栈的经典应用：括号匹配

```cpp
#include <iostream>
#include <string>
#include <stack>
using namespace std;

bool isBalanced(const string& expr) {
    stack<char> st;
    for (char c : expr) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (st.empty()) return false;
            char top = st.top();
            st.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;
            }
        }
    }
    return st.empty();
}

int main() {
    cout << boolalpha;
    cout << isBalanced("{[()]}") << endl;    // true
    cout << isBalanced("{[(])}") << endl;    // false
    cout << isBalanced("(((") << endl;       // false
    return 0;
}
```

### 2.4 栈的应用：逆波兰表达式求值

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <stack>
using namespace std;

int evalRPN(const vector<string>& tokens) {
    stack<int> st;
    for (const string& tok : tokens) {
        if (tok == "+" || tok == "-" || tok == "*" || tok == "/") {
            int b = st.top(); st.pop();
            int a = st.top(); st.pop();
            if (tok == "+") st.push(a + b);
            else if (tok == "-") st.push(a - b);
            else if (tok == "*") st.push(a * b);
            else st.push(a / b);
        } else {
            st.push(stoi(tok));
        }
    }
    return st.top();
}

int main() {
    // (2 + 1) * 3 = 9 → 后缀表达式: 2 1 + 3 *
    vector<string> expr = {"2", "1", "+", "3", "*"};
    cout << evalRPN(expr) << endl;  // 9
    return 0;
}
```

## 三、队列

### 3.1 顺序队列与循环队列

普通顺序队列存在**假溢出**问题：front 前面的空间无法复用。

解决方案：**循环队列**——将数组视为环形，用取模运算实现首尾衔接。

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

class CircularQueue {
private:
    int* data;
    int front;     // 队头下标
    int rear;      // 队尾的下一个位置
    int capacity;

public:
    CircularQueue(int cap = 8) : data(new int[cap]), front(0), rear(0), capacity(cap) {}
    ~CircularQueue() { delete[] data; }

    void enqueue(int val) {
        if (full()) throw runtime_error("Queue overflow");
        data[rear] = val;
        rear = (rear + 1) % capacity;
    }

    void dequeue() {
        if (empty()) throw runtime_error("Queue underflow");
        front = (front + 1) % capacity;
    }

    int peek() const {
        if (empty()) throw runtime_error("Queue is empty");
        return data[front];
    }

    bool empty() const { return front == rear; }
    bool full() const { return (rear + 1) % capacity == front; }
    int size() const { return (rear - front + capacity) % capacity; }
};

int main() {
    CircularQueue q(5);  // 实际可存 4 个（牺牲一个位置区分空/满）
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);

    cout << q.peek() << endl;  // 10
    q.dequeue();
    cout << q.peek() << endl;  // 20
    cout << "Size: " << q.size() << endl;  // Size: 2

    return 0;
}
```

> 循环队列牺牲一个存储位置来区分队空（`front == rear`）和队满（`(rear+1) % cap == front`），这是最经典的实现方式。

### 3.2 链式队列

```cpp
#include <iostream>
using namespace std;

struct QNode {
    int val;
    QNode* next;
    QNode(int v) : val(v), next(nullptr) {}
};

class LinkedQueue {
private:
    QNode* front;
    QNode* rear;
    int len;

public:
    LinkedQueue() : front(nullptr), rear(nullptr), len(0) {}

    ~LinkedQueue() {
        while (front) {
            QNode* tmp = front;
            front = front->next;
            delete tmp;
        }
    }

    void enqueue(int val) {
        QNode* node = new QNode(val);
        if (rear) {
            rear->next = node;
        } else {
            front = node;
        }
        rear = node;
        ++len;
    }

    void dequeue() {
        if (!front) return;
        QNode* tmp = front;
        front = front->next;
        if (!front) rear = nullptr;
        delete tmp;
        --len;
    }

    int peek() const { return front ? front->val : -1; }
    bool empty() const { return front == nullptr; }
    int size() const { return len; }
};

int main() {
    LinkedQueue q;
    q.enqueue(1);
    q.enqueue(2);
    q.enqueue(3);

    while (!q.empty()) {
        cout << q.peek() << " ";
        q.dequeue();
    }
    cout << endl;  // 1 2 3

    return 0;
}
```

### 3.3 双端队列（Deque）

双端队列允许**两端都可以插入和删除**，是栈和队列的超集。

```
        ← push_back / pop_back
  ┌─────────────────────────────┐
  │  front  ...  ...  ...  rear │
  └─────────────────────────────┘
        ← push_front / pop_front
```

STL 中 `std::deque` 的底层是**分段连续内存**（中央控制器 map + 多个 buffer），兼顾了两端 O(1) 操作和较好的缓存性能。

## 四、单调栈

### 4.1 什么是单调栈？

单调栈是一种**栈内元素保持单调递增或递减**的特殊栈。每次新元素入栈前，会弹出所有破坏单调性的栈顶元素。

### 4.2 经典问题：下一个更大元素

给定数组，对每个元素求其**右侧第一个比它大的元素**（不存在则为 -1）。

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreaterElement(const vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1);
    stack<int> st;  // 存下标，栈底到栈顶对应值递减

    for (int i = 0; i < n; ++i) {
        // 当前元素比栈顶大 → 它就是栈顶元素的"下一个更大"
        while (!st.empty() && nums[i] > nums[st.top()]) {
            result[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return result;
}

int main() {
    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> res = nextGreaterElement(nums);

    for (int v : res) cout << v << " ";
    cout << endl;  // 4 2 4 -1 -1

    return 0;
}
```

**执行过程**：

```
i=0: 栈空，push(0)         栈: [0]
i=1: nums[1]=1 < nums[0]=2，push(1)   栈: [0,1]
i=2: nums[2]=2 > nums[1]=1，弹出1，res[1]=2
     nums[2]=2 == nums[0]=2，不弹，push(2)  栈: [0,2]
i=3: nums[3]=4 > nums[2]=2，弹出2，res[2]=4
     nums[3]=4 > nums[0]=2，弹出0，res[0]=4
     push(3)  栈: [3]
i=4: nums[4]=3 < nums[3]=4，push(4)   栈: [3,4]

结果: res = [4, 2, 4, -1, -1]
```

> 单调栈的时间复杂度为 O(n)——每个元素最多入栈一次、出栈一次。

## 五、单调队列

### 5.1 什么是单调队列？

单调队列是一种**队内元素保持单调**的双端队列，常用于**滑动窗口最值**问题。

### 5.2 经典问题：滑动窗口最大值

给定数组和窗口大小 k，求每个窗口内的最大值。

```cpp
#include <iostream>
#include <vector>
#include <deque>
using namespace std;

vector<int> maxSlidingWindow(const vector<int>& nums, int k) {
    deque<int> dq;  // 存下标，队头到队尾对应值递减
    vector<int> result;

    for (int i = 0; i < (int)nums.size(); ++i) {
        // 移除超出窗口的队头
        if (!dq.empty() && dq.front() <= i - k) {
            dq.pop_front();
        }

        // 维护单调性：弹出所有比当前元素小的队尾
        while (!dq.empty() && nums[dq.back()] <= nums[i]) {
            dq.pop_back();
        }

        dq.push_back(i);

        // 窗口形成后记录结果
        if (i >= k - 1) {
            result.push_back(nums[dq.front()]);
        }
    }
    return result;
}

int main() {
    vector<int> nums = {1, 3, -1, -3, 5, 3, 6, 7};
    int k = 3;

    vector<int> res = maxSlidingWindow(nums, k);
    for (int v : res) cout << v << " ";
    cout << endl;  // 3 3 5 5 6 7

    return 0;
}
```

**窗口滑动过程**：

```
窗口位置        最大值
[1  3  -1] -3  5  3  6  7    → 3
 1 [3  -1  -3] 5  3  6  7    → 3
 1  3 [-1  -3  5] 3  6  7    → 5
 1  3  -1 [-3  5  3] 6  7    → 5
 1  3  -1  -3 [5  3  6] 7    → 6
 1  3  -1  -3  5 [3  6  7]   → 7
```

> 单调队列同样是 O(n) 时间——每个元素最多入队一次、出队一次。

## 六、栈与队列的对比与选型

### 6.1 核心对比

| 维度 | 栈 | 队列 |
|------|-----|------|
| 操作规则 | LIFO（后进先出） | FIFO（先进先出） |
| 操作端 | 仅栈顶 | 队尾入、队头出 |
| 典型应用 | 函数调用栈、括号匹配、DFS | BFS、任务调度、缓冲区 |
| STL 容器 | `std::stack` | `std::queue` / `std::deque` |

### 6.2 STL 容器适配器

`std::stack` 和 `std::queue` 都是**容器适配器**——它们不直接存储数据，而是封装底层容器：

```cpp
#include <iostream>
#include <stack>
#include <queue>
#include <list>
using namespace std;

int main() {
    // stack 默认底层是 deque，也可指定为 vector 或 list
    stack<int, list<int>> st;  // 用 list 做底层
    st.push(1);
    st.push(2);
    cout << st.top() << endl;  // 2

    // queue 默认底层是 deque
    queue<int> q;
    q.push(10);
    q.push(20);
    cout << q.front() << endl;  // 10
    cout << q.back() << endl;   // 20

    return 0;
}
```

### 6.3 应用场景速查

| 场景 | 使用结构 |
|------|---------|
| 函数调用与递归 | 栈（系统调用栈） |
| 表达式求值 / 括号匹配 | 栈 |
| 撤销操作（Undo） | 栈 |
| 深度优先搜索（DFS） | 栈（或递归） |
| 广度优先搜索（BFS） | 队列 |
| 生产者-消费者模型 | 队列 |
| 滑动窗口最值 | 单调队列 |
| 下一个更大/更小元素 | 单调栈 |

## 七、总结

| 要点 | 内容 |
|------|------|
| 栈的本质 | 操作受限的线性表（LIFO），用数组或链表实现 |
| 队列的本质 | 操作受限的线性表（FIFO），循环队列解决假溢出 |
| 单调栈 | 维护栈内单调性，O(n) 解决"下一个更大/更小"问题 |
| 单调队列 | 维护队内单调性，O(n) 解决滑动窗口最值 |
| STL 对应 | `stack`（适配器）、`queue`（适配器）、`deque`（双端队列） |
| 核心思想 | 栈和队列的价值不在于存储，而在于**用操作顺序约束来建模问题** |
