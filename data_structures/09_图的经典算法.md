# 09 图的经典算法

## 一、最短路径问题

### 1.1 问题分类

| 类型 | 描述 | 代表算法 |
|------|------|---------|
| 单源最短路 | 从一个起点到所有其他顶点的最短距离 | Dijkstra、Bellman-Ford |
| 全源最短路 | 任意两点之间的最短距离 | Floyd-Warshall |

### 1.2 示例图

后续所有算法使用同一张有向加权图：

```
    0 --4--> 1
    |        |
    2        1
    ↓        ↓
    2 --3--> 3
    |
    5
    ↓
    4
```

边集：(0,1,4), (0,2,2), (1,3,1), (2,3,3), (2,4,5)

## 二、Dijkstra 算法

### 2.1 适用条件

- **非负权边**（若有负权边，使用 Bellman-Ford）
- 单源最短路

### 2.2 算法思想

贪心策略：每次从未确定最短距离的顶点中，选出距离最小的，确定其最短距离，然后松弛其邻居。

```
初始化: dist[0]=0, dist[其余]=∞
已确定集合 S = {}

第 1 步: 取 dist 最小的未确定顶点 0 (dist=0)，加入 S
         松弛: dist[1] = min(∞, 0+4) = 4
               dist[2] = min(∞, 0+2) = 2

第 2 步: 取顶点 2 (dist=2)，加入 S
         松弛: dist[3] = min(∞, 2+3) = 5
               dist[4] = min(∞, 2+5) = 7

第 3 步: 取顶点 1 (dist=4)，加入 S
         松弛: dist[3] = min(5, 4+1) = 5（不变）

第 4 步: 取顶点 3 (dist=5)，加入 S
         松弛: 无更短路径

第 5 步: 取顶点 4 (dist=7)，加入 S

最终: dist = [0, 4, 2, 5, 7]
```

### 2.3 代码实现（优先队列优化）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

struct Edge {
    int to, weight;
};

// 小顶堆元素：{距离, 顶点}
using PII = pair<int, int>;

vector<int> dijkstra(const vector<vector<Edge>>& graph, int src) {
    int n = graph.size();
    vector<int> dist(n, INT_MAX);
    priority_queue<PII, vector<PII>, greater<PII>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (d > dist[u]) continue;  // 已过时的记录，跳过

        for (const auto& [v, w] : graph[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

int main() {
    int n = 5;
    vector<vector<Edge>> graph(n);

    // 有向边
    graph[0].push_back({1, 4});
    graph[0].push_back({2, 2});
    graph[1].push_back({3, 1});
    graph[2].push_back({3, 3});
    graph[2].push_back({4, 5});

    vector<int> dist = dijkstra(graph, 0);

    cout << "从顶点 0 出发的最短距离:" << endl;
    for (int i = 0; i < n; ++i) {
        cout << "  0 -> " << i << ": " << dist[i] << endl;
    }
    // 0 -> 0: 0
    // 0 -> 1: 4
    // 0 -> 2: 2
    // 0 -> 3: 5
    // 0 -> 4: 7

    return 0;
}
```

### 2.4 复杂度

| 实现方式 | 时间复杂度 | 适用 |
|---------|-----------|------|
| 朴素（数组找最小） | O(V²) | 稠密图 |
| 优先队列（二叉堆） | O((V+E) log V) | 稀疏图 |

## 三、Bellman-Ford 算法

### 3.1 适用条件

- **允许负权边**（Dijkstra 不适用）
- 可以**检测负权环**

### 3.2 算法思想

对所有边进行 V-1 轮松弛。每轮遍历所有边 `(u, v, w)`：

```
if dist[u] + w < dist[v]:
    dist[v] = dist[u] + w
```

V-1 轮后若还能松弛，说明存在**负权环**。

### 3.3 代码实现

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

struct Edge {
    int from, to, weight;
};

// 返回空 vector 表示存在负权环
vector<int> bellmanFord(int n, const vector<Edge>& edges, int src) {
    vector<int> dist(n, INT_MAX);
    dist[src] = 0;

    // V-1 轮松弛
    for (int i = 0; i < n - 1; ++i) {
        bool updated = false;
        for (const auto& [u, v, w] : edges) {
            if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                updated = true;
            }
        }
        if (!updated) break;  // 提前终止优化
    }

    // 检测负权环
    for (const auto& [u, v, w] : edges) {
        if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
            return {};  // 存在负权环
        }
    }

    return dist;
}

int main() {
    int n = 5;
    vector<Edge> edges = {
        {0, 1, 4}, {0, 2, 2}, {1, 3, 1}, {2, 3, 3}, {2, 4, 5}
    };

    vector<int> dist = bellmanFord(n, edges, 0);

    if (dist.empty()) {
        cout << "存在负权环!" << endl;
    } else {
        cout << "Bellman-Ford 最短距离:" << endl;
        for (int i = 0; i < n; ++i) {
            cout << "  0 -> " << i << ": " << dist[i] << endl;
        }
    }

    return 0;
}
```

### 3.4 复杂度

| 指标 | 值 |
|------|-----|
| 时间 | O(V × E) |
| 空间 | O(V) |
| 优势 | 支持负权边、检测负权环 |
| 劣势 | 比 Dijkstra 慢 |

## 四、Floyd-Warshall 算法

### 4.1 适用条件

- **全源最短路**（任意两点之间）
- 允许负权边（但不允许负权环）
- 适合**稠密图**或顶点数较少（V < 500）

### 4.2 算法思想

动态规划：`dist[i][j]` 表示 i 到 j 的最短距离。

逐步考虑中间顶点 k：

```
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

三重循环：k 在最外层。

### 4.3 代码实现

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

const int INF = 1e9;

void floyd(vector<vector<int>>& dist) {
    int n = dist.size();
    for (int k = 0; k < n; ++k) {
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
}

int main() {
    int n = 5;
    vector<vector<int>> dist(n, vector<int>(n, INF));

    // 对角线为 0
    for (int i = 0; i < n; ++i) dist[i][i] = 0;

    // 有向边
    dist[0][1] = 4;
    dist[0][2] = 2;
    dist[1][3] = 1;
    dist[2][3] = 3;
    dist[2][4] = 5;

    floyd(dist);

    cout << "全源最短距离矩阵:" << endl;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            if (dist[i][j] >= INF) cout << "INF ";
            else cout << dist[i][j] << "   ";
        }
        cout << endl;
    }

    return 0;
}
```

### 4.4 复杂度

| 指标 | 值 |
|------|-----|
| 时间 | O(V³) |
| 空间 | O(V²) |
| 优势 | 代码极简、一次求出所有点对 |
| 劣势 | V 大时太慢 |

## 五、最小生成树（MST）

### 5.1 什么是最小生成树？

对于**无向加权连通图**，最小生成树是包含所有顶点、边权总和最小的树（V-1 条边）。

### 5.2 Prim 算法

**思想**：从一个顶点出发，每次选连接"已选集合"和"未选集合"的最小边，将新顶点加入。

类似 Dijkstra，但更新的是"到已选集合的距离"而非"到起点的距离"。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

struct Edge {
    int to, weight;
};

int prim(const vector<vector<Edge>>& graph) {
    int n = graph.size();
    vector<bool> inMST(n, false);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    int totalWeight = 0;
    int edgesUsed = 0;

    pq.push({0, 0});  // 从顶点 0 开始

    while (!pq.empty() && edgesUsed < n) {
        auto [w, u] = pq.top();
        pq.pop();

        if (inMST[u]) continue;
        inMST[u] = true;
        totalWeight += w;
        ++edgesUsed;

        for (const auto& [v, weight] : graph[u]) {
            if (!inMST[v]) {
                pq.push({weight, v});
            }
        }
    }

    return totalWeight;
}

int main() {
    // 无向加权图
    int n = 4;
    vector<vector<Edge>> graph(n);

    auto addEdge = [&](int u, int v, int w) {
        graph[u].push_back({v, w});
        graph[v].push_back({u, w});
    };

    addEdge(0, 1, 1);
    addEdge(0, 2, 4);
    addEdge(1, 2, 2);
    addEdge(1, 3, 6);
    addEdge(2, 3, 3);

    cout << "MST 总权重: " << prim(graph) << endl;  // 6 (边: 0-1, 1-2, 2-3)

    return 0;
}
```

### 5.3 Kruskal 算法

**思想**：将所有边按权重排序，依次取最小边，若两端不在同一连通分量则加入（用**并查集**判断）。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class UnionFind {
    vector<int> parent, rank_;
public:
    UnionFind(int n) : parent(n), rank_(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    bool unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;
        if (rank_[rx] < rank_[ry]) swap(rx, ry);
        parent[ry] = rx;
        if (rank_[rx] == rank_[ry]) ++rank_[rx];
        return true;
    }
};

struct Edge {
    int u, v, weight;
};

int kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end(),
         [](const Edge& a, const Edge& b) { return a.weight < b.weight; });

    UnionFind uf(n);
    int totalWeight = 0;
    int edgesUsed = 0;

    for (const auto& [u, v, w] : edges) {
        if (uf.unite(u, v)) {
            totalWeight += w;
            ++edgesUsed;
            if (edgesUsed == n - 1) break;
        }
    }

    return totalWeight;
}

int main() {
    int n = 4;
    vector<Edge> edges = {
        {0, 1, 1}, {0, 2, 4}, {1, 2, 2}, {1, 3, 6}, {2, 3, 3}
    };

    cout << "MST 总权重: " << kruskal(n, edges) << endl;  // 6

    return 0;
}
```

### 5.4 Prim vs Kruskal

| 维度 | Prim | Kruskal |
|------|------|---------|
| 策略 | 从顶点扩展 | 从边选取 |
| 数据结构 | 优先队列 | 排序 + 并查集 |
| 时间复杂度 | O((V+E) log V) | O(E log E) |
| 适用 | 稠密图 | 稀疏图 |

## 六、拓扑排序

### 6.1 什么是拓扑排序？

对**有向无环图（DAG）** 的顶点排成线性序列，使得对每条边 (u, v)，u 都排在 v 前面。

典型应用：课程先修关系、编译依赖、任务调度。

### 6.2 Kahn 算法（BFS）

反复删除入度为 0 的顶点：

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> topologicalSort(int n, const vector<vector<int>>& adj) {
    vector<int> inDegree(n, 0);
    for (int u = 0; u < n; ++u) {
        for (int v : adj[u]) {
            ++inDegree[v];
        }
    }

    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (inDegree[i] == 0) q.push(i);
    }

    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (int v : adj[u]) {
            if (--inDegree[v] == 0) {
                q.push(v);
            }
        }
    }

    // 若 order 大小 < n，说明有环
    if ((int)order.size() != n) return {};
    return order;
}

int main() {
    // 课程依赖：0→1, 0→2, 1→3, 2→3
    int n = 4;
    vector<vector<int>> adj = {
        {1, 2},  // 0 是 1、2 的先修
        {3},     // 1 是 3 的先修
        {3},     // 2 是 3 的先修
        {}
    };

    vector<int> order = topologicalSort(n, adj);

    if (order.empty()) {
        cout << "图中有环，无法拓扑排序!" << endl;
    } else {
        cout << "拓扑排序: ";
        for (int v : order) cout << v << " ";
        cout << endl;  // 0 1 2 3 或 0 2 1 3
    }

    return 0;
}
```

### 6.3 DFS 实现拓扑排序

对 DFS 的完成顺序取逆：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited, vector<int>& order) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v]) {
            dfs(v, adj, visited, order);
        }
    }
    order.push_back(u);  // 后序加入
}

vector<int> topoSortDFS(int n, const vector<vector<int>>& adj) {
    vector<bool> visited(n, false);
    vector<int> order;

    for (int i = 0; i < n; ++i) {
        if (!visited[i]) {
            dfs(i, adj, visited, order);
        }
    }

    reverse(order.begin(), order.end());
    return order;
}

int main() {
    int n = 4;
    vector<vector<int>> adj = {{1, 2}, {3}, {3}, {}};

    vector<int> order = topoSortDFS(n, adj);
    cout << "拓扑排序(DFS): ";
    for (int v : order) cout << v << " ";
    cout << endl;  // 0 1 2 3 或 0 2 1 3

    return 0;
}
```

## 七、算法对比与选型

### 7.1 最短路径算法对比

| 算法 | 适用 | 时间复杂度 | 负权边 | 特点 |
|------|------|-----------|--------|------|
| Dijkstra | 单源、非负权 | O((V+E) log V) | 不支持 | 贪心，最常用 |
| Bellman-Ford | 单源、可负权 | O(V × E) | 支持 | 可检测负权环 |
| Floyd | 全源 | O(V³) | 支持 | 代码极简，V 小时用 |

### 7.2 最小生成树算法对比

| 算法 | 时间复杂度 | 适用 | 核心数据结构 |
|------|-----------|------|-------------|
| Prim | O((V+E) log V) | 稠密图 | 优先队列 |
| Kruskal | O(E log E) | 稀疏图 | 排序 + 并查集 |

### 7.3 选型速查

| 问题 | 推荐算法 |
|------|---------|
| 单源最短路（无负权） | Dijkstra |
| 单源最短路（有负权） | Bellman-Ford |
| 任意两点最短路 | Floyd（V 小）/ 多次 Dijkstra（V 大） |
| 最小生成树（稀疏图） | Kruskal |
| 最小生成树（稠密图） | Prim |
| 有向无环图排序 | 拓扑排序（Kahn / DFS） |
| 判断图是否有环 | 拓扑排序（DAG）/ 并查集（无向图）/ DFS 染色（有向图） |

## 八、总结

| 要点 | 内容 |
|------|------|
| Dijkstra | 贪心 + 优先队列，非负权单源最短路 |
| Bellman-Ford | 逐轮松弛所有边，支持负权，检测负权环 |
| Floyd | DP 三重循环，全源最短路，O(V³) |
| Prim | 从顶点扩展选最小边，适合稠密图 |
| Kruskal | 全局排序边 + 并查集，适合稀疏图 |
| 拓扑排序 | DAG 专属，Kahn（BFS 删入度 0）或 DFS 后序逆 |

> 图算法是数据结构与算法的集大成者——它综合运用了栈/队列（遍历）、堆（Dijkstra/Prim）、并查集（Kruskal）、DP（Floyd）等前面所有知识。掌握这些算法，就具备了处理绝大多数图论问题的能力。
